# 홈 히어로 영상 넣기

홈 화면 맨 위 영상은 **스크롤에 물려 있다.** 내려갈수록 영상이 앞으로 감기고, 올리면 되감긴다.
재생 버튼이 없고 소리도 없다. 스크롤이 곧 재생 손잡이다.

## 넣는 법

파일 두 개를 `public/` 에 두고 커밋하면 끝이다. 코드는 건드릴 필요가 없다.

| 파일 | 역할 |
|---|---|
| `public/hero.mp4` | 영상 본체 |
| `public/hero-poster.jpg` | 영상이 뜨기 전 잠깐 보이는 첫 장면 (없어도 된다) |

```bash
git add public/hero.mp4 public/hero-poster.jpg
git commit -m "chore: 히어로 영상 추가"
git push
```

파일이 없으면 히어로는 글자만 있는 어두운 화면으로 조용히 내려앉는다. 지금이 그 상태다.

## 영상 조건

스크롤로 감는 영상은 일반 재생용 영상과 요구가 다르다. 아래를 지키지 않으면 뚝뚝 끊긴다.

- **길이 5~12초.** 스크롤 세 화면 분량에 맞춰 늘려 쓰므로 짧아도 충분하다
- **용량 10MB 이하.** 퍼블릭 레포에 그대로 올라가고 방문자가 통째로 내려받는다
- **H.264 / MP4.** 가장 널리 읽힌다
- **키프레임을 촘촘하게.** 이게 제일 중요하다. 아무 지점으로나 건너뛰어야 하는데 키프레임이 드물면 그때마다 멈칫한다
- **소리 없음.** 어차피 음소거로 재생된다. 오디오 트랙을 빼면 용량도 준다
- 가로 1920 이하면 충분하다

ffmpeg 이 있다면 이 한 줄로 조건에 맞게 다시 인코딩할 수 있다. `-g 10` 이 키프레임 간격이다.

```bash
ffmpeg -i 원본.mp4 -an -vf "scale=1920:-2,fps=30" -c:v libx264 -crf 26 -g 10 -pix_fmt yuv420p -movflags +faststart public/hero.mp4
```

첫 장면을 포스터로 뽑으려면:

```bash
ffmpeg -i public/hero.mp4 -frames:v 1 -q:v 3 public/hero-poster.jpg
```

## 손볼 수 있는 것

- **스크롤 길이** — `src/pages/Home.tsx` 의 `ScrollVideo` 에 `runway={3}` 을 주면 화면 세 개 높이만큼 스크롤해야 영상이 끝난다. 숫자를 키우면 더 천천히 감긴다
- **따라오는 속도** — `src/components/ScrollVideo.tsx` 의 `0.18`. 키우면 스크롤에 딱 붙고, 줄이면 더 부드럽게 미끄러진다

## 접근성

`prefers-reduced-motion` 을 켠 사람에게는 감기를 하지 않고 첫 장면만 보여준 뒤 바로 다음 내용으로 넘긴다. 어지러움을 호소하는 사람에게 스크롤 연동 영상은 특히 부담이 크기 때문이다.
