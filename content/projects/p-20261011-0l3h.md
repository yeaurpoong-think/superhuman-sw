## 🎁 이걸 하면 얻는 것
- **Before**: 영상 AI를 쓸 때마다 월 구독료를 내고, 생성 횟수가 다 차면 기다려야 했다.
- **After**: 그래픽카드가 받쳐주는 PC라면 **영상·효과음·대사까지 한 번에** 뽑는 AI를 내 컴퓨터에서 **횟수 제한 없이** 돌린다. 구독료는 0원.
- PC 사양이 부족해도 웹 플레이그라운드에서 품질부터 확인해 보고 결정할 수 있다.

## 🎯 핵심 요약
셀카 보정 앱 Facetune을 만든 **Lightricks**가 오디오·영상 동시 생성 모델 **LTX-2.5**를 공개했고, 이걸 클릭 몇 번으로 설치하는 **LTX Desktop** 앱(GitHub 별 약 2,000개, 최신 v1.3.0 / 2026-10-09)도 무료로 내놨다. 다만 내 PC에서 돌리려면 **VRAM 15GB 이상 NVIDIA 그래픽카드**(또는 RAM 32GB 이상 애플 실리콘 맥)와 **약 72GB 여유 공간**이 필요하다. **연 매출 1,000만 달러 이상 회사**는 상업적으로 쓰려면 별도 유료 라이선스가 필요하다.

## 💡 핵심 인사이트
- **소리까지 한 번에 나오는 게 진짜 차별점**: LTX-2는 "영상과 오디오를 동기화해 함께 만드는 첫 DiT 기반 모델"이라고 공식 소개한다. 프롬프트에 대사를 적으면 그 목소리로 말하고, 효과음도 같이 생긴다. 영상 따로, 더빙 따로 할 필요가 없다.
- **"4K·20초"는 따로따로 맞는 말이다**: 공식 README 기준 4K(3840×2176)는 고품질 모드(DFR) 명령어 설정으로 가능하고, 20초 길이는 앱의 Fast 모드 720p에서 지원한다. 단, **720p·20초와 1080p·10초는 VRAM 31GB급 그래픽카드에서만** 선택지가 보인다(16GB 카드에서는 숨겨짐). 원문의 "최대 4K에 20초"는 두 수치를 합친 표현이다.
- **"무료"의 정확한 범위**: 라이선스(LTX-2.x Community License, 2026-08-11)에 따르면 **개인과 연 매출 1,000만 달러 미만 회사는 무료**, 그 이상은 상업용 유료 라이선스 대상이다. 그리고 새 모델 가중치는 Hugging Face 로그인 후 **라이선스 동의**를 해야 받을 수 있다.
- **사양 컷이 꽤 높다**: Windows 기준 RTX 4080(16GB)부터 겨우 해당되고, 보통 사무용 노트북이나 VRAM 8~12GB 게이밍 PC는 로컬 생성이 안 된다. 그래서 원문도 "컴퓨터가 버거우면 웹에서 먼저"라고 덧붙였다.
- **크리에이터가 자료를 감춘 방식 자체가 신호**: 설치 가이드를 댓글→DM으로만 주는 리드 수집형 게시물이다. 실제 설치법은 공식 GitHub Releases에 그대로 공개돼 있다.

## 🛠️ 따라 하는 법 (단계별 가이드)

**준비물 (LTX Desktop 공식 README 기준)**
- Windows 10/11 + **NVIDIA 그래픽카드 VRAM 15GB 이상** + RAM 16GB 이상(32GB 권장)
- 또는 macOS 13 이상 + **애플 실리콘(M 시리즈) + RAM 32GB 이상** (인텔 맥은 불가)
- 디스크 여유 공간 **약 72GB**
- Hugging Face 계정 (무료, 모델 다운로드용)

**STEP 0. 내 PC가 되는지 먼저 확인한다**
1. Windows: `Ctrl + Shift + Esc`로 작업 관리자를 연다 → **성능** 탭 → 왼쪽 목록에서 **GPU 0**(또는 GPU 1)을 누른다.
   → 오른쪽 위에 그래픽카드 이름이, 아래쪽에 **전용 GPU 메모리**가 보인다. 이 숫자가 **16GB 이상**이어야 한다.
2. Mac: 왼쪽 위 사과 메뉴 → **이 Mac에 관하여** → **칩**(Apple M…)과 **메모리**가 32GB 이상인지 본다.
   → 기준에 못 미치면 STEP 4(웹에서 써보기)로 바로 간다.

**STEP 1. Hugging Face 가입과 라이선스 동의**
1. [huggingface.co](https://huggingface.co)에서 무료 가입한다.
2. [Lightricks/LTX-2.5 모델 페이지](https://huggingface.co/Lightricks/LTX-2.5)에 들어가 라이선스 동의 버튼을 누른다.
   → 페이지의 파일 목록이 열리면 다운로드 권한이 생긴 것이다.

**STEP 2. LTX Desktop 설치**
1. [LTX Desktop Releases 페이지](https://github.com/Lightricks/LTX-Desktop/releases)에 들어간다.
2. 맨 위 최신 버전(v1.3.0)의 **Assets**를 펼쳐 내 운영체제용 설치 파일을 받는다(Windows는 `.exe`, Mac은 `.dmg`).
3. 설치 파일을 실행하고 안내대로 설치한 뒤 **LTX Desktop**을 연다.
   → 첫 실행 화면에서 Hugging Face 로그인을 요청한다. STEP 1 계정으로 로그인한다.
4. 모델 다운로드가 시작된다(약 72GB, 인터넷 속도에 따라 수십 분).
   → 다운로드가 끝나면 프롬프트 입력창이 활성화된다.

**STEP 3. 첫 영상 만들기**
1. 기본 모델은 **LTX 2.5 Fast**다(설정 → Models에서 바꿀 수 있음).
2. 프롬프트에 장면 + 카메라 + 소리 + 대사를 한 덩어리로 적는다. 공식 예시처럼 쓰면 된다.
   ```
   A medium close-up of a woman applying serum in a bright bathroom, soft morning light. She looks at the camera and says, "Three drops, every night." A gentle water drip sound is heard. Static camera, shallow depth of field.
   ```
3. 해상도·길이를 고르고 생성한다.
   → 결과 영상에 대사 음성과 효과음이 함께 들어 있는지 재생해서 확인한다.

**STEP 4. PC가 안 되면 웹에서 먼저**
- [LTX 콘솔 플레이그라운드](https://console.ltx.video/playground)에서 같은 모델을 브라우저로 써볼 수 있다. 사양 투자 전에 품질부터 확인하는 용도로 좋다.

**자주 막히는 곳**
- 모델 다운로드가 시작 안 됨 → Hugging Face 모델 페이지에서 라이선스 동의를 안 한 경우가 대부분이다.
- 해상도·길이 선택지가 생각보다 적음 → VRAM 16GB 카드에서는 720p·20초, 1080p·10초 옵션이 일부러 숨겨진다(정상).
- 디스크 부족 → 2.3 버전이나 추가 이미지 모델까지 받으면 72GB보다 커진다. Fast 기본 팩만 받는다.

## 💼 활용 예시
- **BeauT오빠 / 개인 숏폼**: 원고가 정해진 짧은 제품 연출 컷이나 B-roll을 구독료 없이 뽑는다. 대사까지 넣을 수 있어서 "AI 성우"를 따로 붙일 필요가 없다.
- **숏폼 트렌드 리포트 숏폼**: 리포트 숏폼의 인트로·전환 컷을 직접 생성해서, 남의 영상 클립을 쓰지 않고도 화면을 채운다(저작권 리스크 감소).
- **케이시크릿 업무에 쓸 경우**: 회사 연 매출이 1,000만 달러(약 140억 원) 이상이면 상업용 유료 라이선스 대상이다. 업무 적용 전 확인 필요.

## ⚠️ 주의사항
- **출처 신뢰도**: 원본은 2차 소개 게시물이다. 회사(Lightricks), 오디오·영상 동시 생성, 사양, 4K 설정, 라이선스 조건은 **공식 GitHub·라이선스 원문으로 재검증**했다. "설치·세팅 20분"은 원문 인용(모델 다운로드 72GB는 별도 시간 소요).
- **"8월 무료 공개"**: 현재 라이선스(LTX-2.x Community License) 날짜가 2026-08-11로 원문과 맞는다. LTX-2 첫 공개는 그 이전(2026-01)이다.
- **상업 이용**: 연 매출 1,000만 달러 이상 기업은 유료 라이선스 필요. 개인 크리에이터는 무료.
- **사양**: VRAM 15GB 미만 Windows, RAM 32GB 미만 맥, 인텔 맥은 로컬 생성 불가.
- 생성 영상에 실존 인물·브랜드 로고를 넣는 건 초상권·상표권 문제가 될 수 있다.
