## 🎯 핵심 요약

헤르메스 0.14 업데이트로 단순 챗봇형 에이전트를 넘어 **통합 운영체제(OS)**로 진화했다. 기억 연장, Google Workspace 연동, PC 원격 제어, Codex CLI 무료 연동, 기기간 세션 이관(Handoff), 명령을 스스로 쪼개 병렬 실행하는 Sub-Goal 오케스트레이션까지 총 9가지 핵심 업데이트가 포인트다.

## 💡 핵심 인사이트

- **기억 연장**: 사용자 정보를 더 정확히 기록·관리하면서 토큰 소모가 줄어 응답 속도가 향상되고, 세션마다 전체 대화를 다시 로딩하는 번거로움이 사라졌다.
- **Google Workspace 통합**: Docs 자동 작성·저장, Sheets 데이터 분석, Drive 파일 관리, Gmail 자동화까지 — 한국 직장인 업무 환경에 특히 유용하다.
- **PC 원격 제어**: 텔레그램·디스코드·슬랙으로 명령을 내리면 연동된 컴퓨터가 실제로 작업을 수행한다(보안상 반드시 Docker 환경 안에서 사용 권장). Claude Dispatch, Playwright와 유사한 개념.
- **코딩 워커(Codex CLI 통합)**: ChatGPT Plus 구독자는 API 토큰 소모 없이 헤르메스 안에서 백그라운드 코딩 작업을 돌릴 수 있다.
- **Handoff**: 카페·사무실·집 어디서든 맥락이 끊기지 않고 이어진다 — 이전엔 Claude Code에만 있던 기능.
- **Sub-Goal 오케스트레이션**: "3D 슈팅 게임 HTML로 만들어줘" 같은 명령을 헤르메스가 스스로 구조 설계 → 로직 코딩 → 그래픽·애니메이션 → 테스트·버그픽스로 쪼개 병렬 실행 — "자는 동안 완료되어 있는" 진짜 자동화.

## 🛠️ 적용법 가이드

업데이트 자체는 자동 반영되지만, 팀 단위로 가치를 끌어내려면 상황별로 이렇게 붙이면 된다:
- 회의가 많은 팀 → 회의록 자동 작성 요청
- 외근·현장직 → PC 원격 제어로 컴퓨터 작업 자동화
- Google Docs 중심 팀 → Workspace 연동으로 문서 자동 생성
- 코딩이 필요한 막내부터 수석까지 → 코딩 워커로 Sub-Goal 수행 위임

## 💼 활용 예시

- "오늘 회의 내용 구글 닥스로 정리해서 팀폴더에 저장해줘" → 작성·저장까지 자동 완료
- "견적서 작성해줘" (업무 범위·미팅 내용만 전달) → 구글 닥스로 자동 출력
- 인스타·릴스·유튜브용 단편 영상을 헤르메스 내부에서 기획~출력까지 처리 (Pika, Runway 등 외부 서비스 의존도 최소화)

## ⚠️ 주의사항

- PC 원격 제어는 보안을 위해 **반드시 Docker 환경 안에서만** 사용할 것
- ChatGPT Plus 구독이 있어야 코딩 워커(Codex CLI) 기능을 추가 비용 없이 쓸 수 있다 — 없으면 API 토큰 비용 발생
- 기존 LLM 채팅 대비 "AI 직원처럼 자율 분해·병렬 실행"하는 방식이라, 결과를 검증 없이 그대로 신뢰하기보다 첫 도입 단계에서는 결과물을 확인하는 습관이 필요하다
