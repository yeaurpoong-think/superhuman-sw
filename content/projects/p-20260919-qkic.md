## 🎯 핵심 요약

"Open Generative AI"는 이미지·영상·립싱크 생성을 200개 넘는 모델로 한 화면에서 처리하는 무료 오픈소스 데스크톱 앱이다(GitHub `Anil-matcha/Open-Generative-AI`, MIT 라이선스, 스타 2만8천 개 이상 — 실존·활발히 관리 중인 프로젝트로 확인됨). 설치 → 첫 실행 경고 해제 → 탭 구조 파악 → 이미지/영상 첫 생성 → 카메라 값으로 화면 톤 잡기 → 필요하면 자동화 연결까지, 총 7단계로 처음 써보는 사람도 10분 안에 감을 잡을 수 있도록 설계된 가이드다. 앱 자체는 완전 무료지만, 클라우드 모델 실행은 Muapi.ai라는 외부 서비스를 거치므로 "앱은 무료, 다량 생성은 유료 전환 가능" 구조로 이해하는 게 정확하다.

## 💡 핵심 인사이트

- 여러 AI 영상·이미지 툴을 각각 구독하는 대신, 하나의 앱에서 Flux·Kling·Seedream 등 다양한 모델을 갈아타며 비교할 수 있다는 게 핵심 가치다.
- "영화 같은 느낌"을 프롬프트 문장으로 애매하게 표현하는 대신, Cinema Studio 탭에서 초점거리·조리개 같은 실제 촬영 값을 숫자로 지정하면 결과 품질이 확연히 달라진다.
- Windows/macOS 첫 실행 시 뜨는 보안 경고는 코드 서명이 없는 오픈소스 배포물의 흔한 특징이지 악성 프로그램 신호가 아니다 — 이 단계에서 겁먹고 삭제하는 사람이 많아 별도로 강조되어 있다.
- 화면 클릭 없이 명령어로 반복 생성하고 싶다면 `muapi-cli`를 설치하고 클로드 코드/코덱스 같은 AI 코딩 도구에 전용 스킬(`SamurAIGPT/Generative-Media-Skills`)을 붙이는 자동화 경로도 마련되어 있다.
- 클라우드 API 비용이 부담스럽다면 앱 설정의 로컬 모델 기능으로 이미지 생성만큼은 내 컴퓨터에서 계정 키 없이 완전 무료로 돌릴 수 있다(영상 모델은 별도 GPU 서버 필요).

## 🛠️ 적용법 가이드 (Windows 기준, 7단계)

### STEP 1. 설치 파일 받기 (약 2분)

[릴리스 페이지](https://github.com/Anil-matcha/Open-Generative-AI/releases)에서 최신 버전 중 **"Setup"이 붙은 `.exe`** 파일을 받는다. 설치 없이 먼저 체험만 하고 싶다면 이 단계를 건너뛰고 `muapi.ai/open-generative-ai`에서 브라우저로 바로 써도 된다 — 단, 로컬(내 컴퓨터에서 직접 실행하는) 모델 기능은 설치본에만 있다.

### STEP 2. 첫 실행 경고 해제하기 (약 3분)

Windows에서 파란 SmartScreen 경고창이 뜨면 **"추가 정보" → "실행"** 순으로 클릭하면 된다. 코드 서명 비용을 지불하지 않은 오픈소스 배포물에서 흔히 나오는 안내이지, 바이러스 경고가 아니다. 설치가 끝나고 앱을 열면 무료 계정으로 로그인해야 클라우드 모델 목록이 열린다.

### STEP 3. 탭(스튜디오) 구조 먼저 파악하기 (약 3분)

탭이 곧 사용 가능한 모델 묶음이므로, 탭을 잘못 고르면 원하는 모델이 아예 안 보인다.

| 탭 | 용도 |
|---|---|
| Image Studio | 글로 이미지 생성, 또는 기존 이미지 편집 |
| Video Studio | 글로 영상 생성, 또는 이미지 한 장을 움직임으로 변환 |
| Cinema Studio | 카메라 값을 직접 지정해 영화 같은 장면 연출 |
| Lip Sync Studio | 얼굴 사진/영상에 음성을 입혀 립싱크 |

이미지를 업로드하지 않으면 텍스트-생성 모델이, 참고 이미지를 올리면 편집/애니메이션 모델이 자동으로 목록에 뜬다.

### STEP 4. 첫 이미지·영상 만들어보기 (약 5분)

Image Studio에서 모델 하나를 고르고 원하는 장면을 문장으로 최대한 구체적으로 적어 생성하면, 잠시 후 결과가 화면과 기록 영역에 나타난다. 그 이미지를 Video Studio의 시작 프레임으로 올리고 카메라 움직임을 문장으로 지시하면 정지 이미지가 짧은 영상으로 바뀐다. 첫 생성은 대기열 때문에 다소 걸릴 수 있다.

### STEP 5. Cinema Studio로 화면 톤 잡기 (약 5분)

"영화처럼"이라고 프롬프트에 적는 것보다 카메라 값을 직접 고르는 쪽이 훨씬 정확한 결과를 낸다.

- **초점 거리**: 8mm(넓게 담김) ~ 85mm(대상만 크게 잡힘) 범위
- **조리개**: f/1.4(배경 흐림) · f/4(무난) · f/11(전체 선명)

인물 위주 감성 컷은 35mm + f/1.4, 제품·풍경은 24mm + f/11로 시작하는 것을 추천한다.

### STEP 6. 자동화 연결하기 (약 10분, 선택)

터미널(Windows는 PowerShell)에서 아래 명령으로 CLI 도구와 AI 코딩 도구용 스킬을 설치한다.

```bash
npm install -g muapi-cli
muapi auth configure
npx skills add SamurAIGPT/Generative-Media-Skills --all
```

연결이 잘 됐는지는 다음 명령으로 확인한다 — 사용 가능한 이미지 모델 목록이 출력되면 정상이다.

```bash
muapi image models
```

이후 클로드 코드/코덱스 같은 AI 코딩 도구에 "이 스킬로 이미지 N장과 영상 하나를 만들어서 특정 폴더에 저장해달라"는 식으로 목표와 저장 경로를 지정해 요청하면, 도구가 알아서 모델을 고르고 생성·저장까지 진행한다. 지정한 폴더에 실제 파일이 생겼는지 확인하는 것이 완료 기준이다.

### STEP 7. 무료 범위 이해하기 (약 3분)

- 앱 자체는 MIT 라이선스 오픈소스 — 설치·사용·수정 전부 무료.
- 클라우드 모델 생성은 Muapi.ai 서비스를 경유하며, 무료 계정으로 시작 가능하지만 무거운 모델을 많이 돌리면 크레딧이 필요할 수 있다.
- 비용을 아예 안 쓰고 싶다면 앱 설정의 **로컬 모델** 기능으로 실행 엔진을 설치하고 모델을 내려받아 계정 키 없이 이미지 생성이 가능하다. 다만 메모리 8GB급 기기라면 가벼운 모델부터 시작해야 하고, 영상 모델은 별도 GPU 장비가 필요하다.

## 💼 활용 예시

- 마케팅 시안 이미지를 여러 모델로 빠르게 비교 생성
- 신제품 소개용 이미지 여러 장 + 짧은 소개 영상을 자동화 스킬로 한 번에 생성
- 인물 인터뷰·소개 영상에 Cinema Studio 카메라 값을 적용해 톤 다운/업 조절

## ⚠️ 주의사항

- 콘텐츠 필터가 없는 것이 이 프로젝트의 특징 중 하나로 소개되어 있다 — 회사 업무용으로 쓴다면 생성물에 대한 자체 검수 절차를 별도로 마련해두는 것이 안전하다.
- 자동화(muapi-cli, 스킬 연결) 단계는 터미널/Node.js 사용 경험이 필요하다. 처음이라면 STEP 1~5의 화면 조작만으로도 충분히 체험 가능하다.
- 계정 비밀번호와 API 키는 화면에 노출하거나 파일·저장소에 커밋하지 않는다.
- 설치 파일은 반드시 공식 GitHub 릴리스 페이지에서만 받을 것 — 그 외 경로의 배포본은 신뢰하지 않는다.

## 🔧 자주 막히는 지점

| 증상 | 원인 | 해결 |
|---|---|---|
| Windows에서 파란 경고창 | 코드 서명 없는 설치 파일 | "추가 정보" → "실행" 클릭 |
| 원하는 모델이 목록에 없음 | 탭/입력 방식이 다름 | 이미지 생성 vs 편집 구분, 참고 이미지 업로드 여부 확인 |
| 생성 버튼 눌러도 반응 없음 | 로그인 또는 키 미설정 | 무료 계정으로 재로그인 |
| `command not found: npm` | Node.js 미설치 | nodejs.org에서 LTS 버전 설치 후 터미널 재시작 |
| 로컬 모델이 너무 느림 | 메모리 부족으로 CPU 실행 | 더 가벼운 모델로 교체하거나 클라우드 모델 사용 |
