## 🎁 이걸 하면 얻는 것
지금까지 네이버 블로그 글이나 유튜브 영상을 보고 "이걸 인스타 카드뉴스로도 만들어볼까" 하면, 캡처하고 → 텍스트 옮기고 → 디자인 툴 열고 → 슬라이드 7장 손으로 배치하는 데 최소 30분~1시간이 들었을 것이다. 이 도구를 세팅하면 **웹 링크(블로그/뉴스/유튜브) 하나만 붙여넣으면 AI가 알아서 요약→카드뉴스(또는 영상, 블로그 초안)까지 1~2분 안에 만들어준다.** 원문 릴스는 "허리디스크" 관련 네이버 블로그 글 하나를 붙여넣어 7장짜리 카드뉴스를 완성하는 과정을 보여준다. 대신 무료 플랜은 매달 크레딧 50개 한도 + 결과물에 워터마크가 붙는다 — "일단 무료로 감 잡아보고, 계속 쓸 만하면 유료 전환" 용도에 맞는 도구다.

## 🎯 핵심 요약
릴스 속 도구의 정체는 한국 스타트업 **미리내 AI(Mirinae AI, 대표 박규태)가 만든 SNS 콘텐츠 자동화 서비스 "Mirr"**(공식 사이트 `mirra.my`)다. 핵심 기능은 **"링크를 콘텐츠로"** — 블로그/쇼핑몰/뉴스/유튜브 링크를 붙여넣으면 AI가 카드뉴스·영상·블로그 초안으로 변환한다. 무료 플랜은 **월 50 크레딧 + 워터마크 적용**이며, 유료 최저가 Launch 플랜은 **월 $19(SNS 계정 1개, AI 크레딧 월 500개, 워터마크 제거)**다. 원문 릴스 캡션에는 "댓글로 '미르' 남기면 정보줌"이라는 리드젠 유도 문구가 있었다 — 정확한 프롬프트 입력값이나 세부 설정은 화면에 노출되지 않았다.

## 💡 핵심 인사이트
- **"카드뉴스/영상/블로그 셋 다 자동 생성"이 이 도구의 차별점이다** — 공식 사이트 카피가 "Not just video. Not just carousels. One idea, rebuilt for every channel."(하나의 소재를 채널마다 다르게 재구성)라고 명시한다. 실제 릴스에서도 링크 하나를 붙여넣은 뒤 "카드뉴스 만들기 / 영상 만들기 / 블로그 만들기" 세 가지 버튼이 동시에 뜨는 화면이 나온다.
- **무료 플랜의 정확한 한도는 "월 50 크레딧 + 워터마크"다** — Mirr 공식 요금제 FAQ 원문: "무료 플랜은 매월 50 크레딧과 워터마크가 적용됩니다. Mirr를 반복적인 마케팅 운영에 쓰기 시작하면 Launch를 선택하세요." 카드뉴스 1건 제작에 크레딧이 정확히 몇 개 소모되는지는 공개 페이지에 숫자로 명시되어 있지 않다 — 가입 후 실제 생성해보며 확인이 필요하다.
- **가장 저렴한 유료 플랜(Launch, $19/월)도 SNS 계정은 1개만 연결된다** — SR바이오텍처럼 여러 계정(회사 인스타+블로그 등)을 함께 운영하려면 Build($49/월, 계정 5개) 이상이 필요하다.
- **릴스 자체는 정확한 조작법을 숨긴 리드젠 콘텐츠다** — 캡션에 "이거 쓰고 경쟁사한테 신고먹었어… 댓글로 미르 남기면 정보줌"이라고 적혀 있어, 화면에 보이는 것 이상의 세부 설정(예: 어떤 카드뉴스 스타일을 골랐는지, 몇 번 수정했는지)은 원천적으로 공개되지 않는다. 다만 도구 자체는 공개 웹사이트에서 누구나 가입해 확인할 수 있으므로, 아래 "따라 하는 법"은 원문 릴스가 아니라 Mirr 공식 사이트를 직접 조사해 재구성했다.
- **가입 절차는 "7일 무료체험, 신용카드 불필요"로 시작한다** — 회원가입 페이지 문구가 이렇게 명시하며, 이는 위 요금제 페이지의 "무료 플랜(월 50 크레딧)"과는 별개 문구다. 즉 가입 직후엔 임시 체험 크레딧이 주어지고, 이후 무료 플랜(월 50 크레딧+워터마크) 또는 유료 플랜으로 전환하는 구조로 보인다 — 정확한 체험-무료 전환 시점은 가입해봐야 확인 가능하다.

## 🛠️ 따라 하는 법 (단계별 가이드)

> ⚠️ **준비물**
> - 이메일 주소 (또는 구글 계정) — 회원가입용
> - 카드뉴스로 만들고 싶은 웹 링크 하나(블로그 글, 뉴스 기사, 유튜브 영상 등)
> - 결제 정보는 필요 없다 — 가입 시 "신용카드 불필요(No credit card required)"라고 공식 명시됨

### STEP 1. Mirr 가입
1. 브라우저에서 https://www.mirra.my 접속
2. 화면 우측 상단 **"무료로 시작하기"**(영문 사이트는 "Start for Free") 클릭
3. 이메일·비밀번호를 입력하고 **"Sign Up"** 클릭 — 또는 그 아래 **"Google"** 버튼으로 구글 계정 연동 가입도 가능
4. **확인 지점**: 가입이 끝나면 화면이 Mirr의 대시보드(왼쪽에 메뉴 목록, 가운데 "링크를 콘텐츠로" 같은 큰 배너가 있는 화면)로 넘어간다.

### STEP 2. 워크스페이스 확인
1. 화면 좌측 상단에 **"Personal Workspace"**라는 표시가 보인다 — 개인용 작업공간이 기본 생성되어 있다는 뜻이다.
2. 왼쪽 사이드바에 다음 메뉴들이 보이는지 확인한다: **AI로 기획 / AI로 콘텐츠 제작 / 콘텐츠 예약 / 콘텐츠 캘린더 / 콘텐츠 성과 / 자동 DM / 댓글 관리 / SNS 계정 연동·관리**

### STEP 3. 링크를 카드뉴스로 변환하기
1. 대시보드 중앙 또는 사이드바에서 **"🔗 링크로 콘텐츠 만들기"** 섹션을 찾는다 (부제: "웹링크, 카드뉴스, 영상, 블로그 초안, 포스트를 즉시 변환하세요")
2. 입력창에 원하는 웹페이지 URL을 붙여넣는다 (예시로 뜨는 placeholder는 `example.com/article` 형태)
3. **확인 지점**: 링크를 넣고 실행하면 화면에 "카드에 쓸 수 있는 사진을 고르고 있어요" 같은 진행 메시지와 함께 진행률/남은 시간(예: "약 63초 남음")이 표시된다 — AI가 원문을 분석하고 이미지를 고르는 중이라는 뜻이니 기다린다.
4. 처리가 끝나면 원문 내용이 요약된 화면과 함께 하단에 **"카드뉴스 만들기 / 영상 만들기 / 블로그 만들기"** 세 가지 선택지가 나타난다. 원하는 형식을 클릭한다.

### STEP 4. 카드뉴스 결과물 확인 및 수정
1. "카드뉴스 만들기"를 선택하면 여러 장(원문 사례는 7장)짜리 슬라이드가 자동 생성된다. 화면 하단에 **1/7, 2/7…** 형태로 페이지 번호가 표시된다.
2. 각 슬라이드는 제목+본문 텍스트가 이미지 위에 얹혀진 형태다. 슬라이드를 넘기며 오탈자나 어색한 문장이 없는지 확인한다.
3. 화면 상단에 **비율 선택(예: 4:5)**, **다운로드**, **복사**, **삭제** 아이콘이 있다 — 인스타그램에 올릴 거면 4:5 또는 1:1 비율을 선택한다.
4. **확인 지점**: 무료 플랜에서 다운로드한 이미지에는 워터마크가 찍혀 나온다. 워터마크 없이 쓰려면 유료 플랜(Launch 이상, $19/월~) 결제가 필요하다.

### STEP 5. SNS 계정 연동해서 바로 발행하기 (선택)
1. 사이드바에서 **"SNS 계정 연동-관리"** 메뉴로 이동한다
2. 인스타그램/유튜브/스레드 등 원하는 계정을 로그인 연동한다
3. 카드뉴스 제작 화면에서 바로 **"콘텐츠 예약"** 메뉴로 넘어가면, 만든 카드뉴스를 예약 발행하거나 캘린더에 배치할 수 있다
4. **확인 지점**: 연동이 끝나면 사이드바 "콘텐츠 캘린더"에 예약된 게시물이 날짜별로 표시된다.

## 💼 활용 예시
- **BeauT오빠(뷰티 인스타 계정) 콘텐츠 파이프라인**: 팩트체크된 뷰티 관련 뉴스/블로그 링크를 붙여넣어 카드뉴스 초안을 빠르게 뽑아본 뒤, "BeautyIsT.NotF." 톤에 맞게 텍스트만 수정해서 올리는 식으로 제작 시간을 단축할 수 있다. 다만 무료 플랜 워터마크 때문에 실제 발행용으로는 유료 전환이나 별도 워터마크 제거 작업이 필요하다.
- **서고(superhuman-sw) 카드 제작 실습**: "링크 하나로 카드뉴스/영상/블로그를 동시에 만든다"는 컨셉 자체가 서고의 지향점(SNS 지식을 소화해서 콘텐츠로 재생산)과 맞닿아 있어, 서고 카드 작성 워크플로우 자체를 이런 자동화 도구와 비교해보는 참고 사례로 쓸 수 있다.
- **SR바이오텍 마케팅팀 참고용**: 회사 블로그/뉴스 링크를 카드뉴스로 빠르게 변환해 SNS 채널에 올리는 실험 도구로 검토해볼 수 있다 — 단, Build 플랜($49/월) 이상이어야 SNS 계정 5개까지 연동 가능해 여러 채널 운영에 적합하다.

## ⚠️ 주의사항
- **이 릴스는 리드제너레이션(광고) 콘텐츠다** — 캡션에 "댓글로 '미르' 남기면 정보줌"이라는 문구가 있어, 정확한 프롬프트 입력값이나 세부 조작(예: 카드뉴스 스타일 선택 옵션, 몇 번 재생성했는지)은 화면에 공개되지 않았다. 위 STEP 1~5는 릴스 화면 캡처가 아니라 **Mirr 공식 사이트에 직접 가입하고 요금제 페이지를 조사해 재구성**한 것이다.
- **무료 플랜 한도(월 50 크레딧 + 워터마크)는 Mirr 공식 요금제 FAQ 원문 그대로다** — 재검증 불필요(1차 공식 출처). 다만 "카드뉴스 1건 제작에 크레딧이 몇 개 소모되는지"는 공개 페이지에 없어 확인 안 됨 — 실제 가입 후 크레딧 소모량을 직접 확인해야 한다.
- **가입 시 뜨는 "7일 무료체험, 신용카드 불필요" 문구와 요금제 페이지의 "무료 플랜(월 50 크레딧)"은 서로 다른 단계일 가능성이 있다** — 정확한 체험판→무료 플랜 전환 시점과 조건은 명시적으로 확인하지 못했다.
- **운영사는 국내 스타트업(미리내 AI, 사업자등록번호 764-53-00982, 대표 박규태)**이다 — 서비스 안정성·데이터 보관 정책 등은 이용약관/개인정보처리방침을 별도로 확인할 것을 권한다.
- **원문 릴스 계정(@ai_mst.mirr)은 도구 자체 제작사가 아니라 이 도구를 활용한 콘텐츠 채널로 보인다** — 계정명과 도구명(Mirr)이 유사해 혼동하기 쉬우나, 공식 서비스 사업자 정보(미리내 AI)와 릴스 게시자는 별개 주체일 수 있다.
