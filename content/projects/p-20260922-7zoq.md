## 요약

Y Combinator 대표 Garry Tan이 실제로 매일 쓰는 클로드(Claude) 세팅 "gstack"을 소개하는 노션 가이드. 터미널 없이 클로드 데스크탑 앱의 Code 탭에 문장 한 줄만 붙여넣으면 5분 만에 설치되는 방식으로 소개됨.

- 원본: [github.com/garrytan/gstack](https://github.com/garrytan/gstack) (MIT 라이선스, 무료)
- 만든 사람: Garry Tan (Y Combinator 대표)

## 준비물

1. 클로드 또는 GPT 데스크탑 앱 (최신 버전, Code 탭이 보여야 함)
2. 클로드/GPT 유료 플랜 (Pro/Plus 이상 — Code 탭은 무료 플랜에서 안 열림)

## 설치 방법

1. 클로드 데스크탑 앱을 연다
2. 맨 위 Chat / Cowork / Code 중 **Code** 탭을 누른다 (안 보이면 앱 업데이트)
3. 아래 문장을 입력창에 붙여넣고 Enter:
   ```
   https://github.com/garrytan/gstack을 내 컴퓨터에 설치해줘. 설치 후 이상 없는지, 제대로 작동하는지까지 검수해줘.
   ```
4. 3~5분 소요, 권한 요청은 자동 건너뛰기로 두면 편함

## 설치하면 뭐가 달라지나

클로드가 일을 혼자 다 하지 않고, 역할을 나눠 순서대로 처리하도록 강제됨 — 질문 → 설계 → 제작 → 자체 검토 → 실제 브라우저로 확인 후에야 "완료" 처리.

**바로 체감되는 3가지 명령어**
- `/office-hours` — 아이디어를 던지면 질문 6개로 파고듦(진짜 수요가 있나, 지금은 어떻게 버티나, 누가 가장 절실한가, 가장 좁게 시작하면 뭔가). 답변을 종합해 설계 문서를 생성, 이후 단계가 이 문서를 이어받음. 사업 아이디어·콘텐츠 기획·사이드 프로젝트 전반에 적용 가능
- `/plan-ceo-review` — 대표 시점에서 계획을 재검토("이게 진짜 사람들이 원하는 건가, 더 큰 기회를 놓치는 건 아닌가"), 범위 확대/축소를 제안 — 혼자 일할 때 없는 "말리는 사람" 역할
- `/qa` — 실제 브라우저를 열어 버튼을 하나씩 눌러보며 문제를 찾아 수정. "된 것 같다"가 아니라 직접 확인한 결과를 보고

**그 외 포함된 역할(총 23개 명령어)**
개발 팀장(`/plan-eng-review`), 디자이너(`/plan-design-review`, AI 티 나는 화면 필터링), 시니어 개발자(`/review`, 버그 탐지), 보안 감사(`/cso`), 배포 담당(`/ship`), 주간 회고(`/retro`) 등. 입력창에 `/`를 치면 전체 목록 확인 가능.

## 참고 사항

- Hermes 환경(에이전트/스킬 구조)과 개념적으로 유사한 "역할 분리 + 슬래시 커맨드 워크플로" 패턴 — SR바이오텍/개인 프로젝트에 적용 가능성 있는지 검토해볼 만함
- 클로드 유료 플랜(Pro 이상) 필수라는 진입 장벽 있음
- 실제 설치·사용 여부는 아직 검증 안 함(원문 리서치 단계)
