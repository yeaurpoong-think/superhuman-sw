## 🎯 핵심 요약

Y Combinator 대표 **Garry Tan**이 실제로 매일 쓴다고 공개한 Claude 세팅 "gstack". 터미널 없이 클로드 데스크탑 앱 **Code 탭**에 문장 한 줄만 붙여넣으면 3~5분 만에 설치되고, 이후 클로드가 혼자 다 처리하는 대신 **23개 슬래시 커맨드**로 역할을 나눠 순서대로(질문→설계→제작→검토→실브라우저 확인) 작업하도록 강제하는 구조. 단, 클로드/GPT **유료 플랜(Pro/Plus 이상)** 이 필수 조건.

## 💡 핵심 인사이트

- **설치 명령이 문장 하나**: `https://github.com/garrytan/gstack을 내 컴퓨터에 설치해줘. 설치 후 이상 없는지, 제대로 작동하는지까지 검수해줘.`를 Code 탭에 붙여넣으면 끝 — 별도 CLI·터미널 지식 불필요
- **`/office-hours`가 아이디어를 질문 6개로 검증**: "진짜 수요가 있나, 지금은 어떻게 버티나, 누가 가장 절실한가, 가장 좁게 시작하면 뭔가" 등을 물어 설계 문서를 자동 생성 — 이후 모든 단계가 이 문서를 근거로 진행됨
- **`/plan-ceo-review`가 "말리는 사람" 역할을 대신함**: 대표 시점에서 "이게 진짜 원하는 건가, 더 큰 기회를 놓치는 건 아닌가"를 따져 범위 확대/축소를 제안 — 1인 작업자에게 구조적으로 없는 검토 단계를 보완
- **`/qa`는 "된 것 같다"가 아니라 실제 클릭 결과를 보고**: 브라우저를 직접 열어 버튼을 하나씩 눌러보고 문제를 고침 — 코드/빌드 통과와 실제 화면 동작이 다른 문제(2026.09 superhuman-sw 사례)를 구조적으로 막는 장치
- **총 23개 명령어**: 개발 팀장(`/plan-eng-review`), 디자이너(`/plan-design-review`, AI 티 나는 화면 필터링), 시니어 개발자(`/review`), 보안 감사(`/cso`), 배포(`/ship`), 주간 회고(`/retro`) 등 — `/` 입력 시 전체 목록 확인 가능

## 🛠️ 적용법 가이드

1. 클로드 데스크탑 앱을 열고 최신 버전인지 확인(Code 탭이 안 보이면 업데이트)
2. Chat / Cowork / **Code** 탭 선택
3. 위 설치 문장을 붙여넣고 Enter — 권한 요청은 자동 건너뛰기로 두면 편함
4. 3~5분 후 `/` 입력해 23개 명령어 목록 확인

## 💼 활용 예시

- Hermes 스킬 구조(역할별 분리, 트리거 조건)와 개념적으로 유사한 패턴 — BeauT오빠 콘텐츠 자동화나 서고 라이브러리 유지보수에서 "역할 분리 + 슬래시 커맨드" 워크플로를 직접 벤치마크해볼 수 있음
- `/qa`의 "실제 클릭해서 확인" 원칙은 서고 라이브러리 자체 개발(칸반 드래그 버그 등)에도 그대로 적용 가치 있음
