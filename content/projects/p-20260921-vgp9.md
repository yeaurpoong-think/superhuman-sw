## 🎯 핵심 요약
**ThreeUI는 움직이는 3D 웹 배경·버튼·소개 페이지를 모아둔 무료 자료실이다.** Design+Code(제작사 MengTo)가 커뮤니티판 전체를 오픈소스(MIT)로 공개했고, 로그인 없이 164개(무료 변형 141개 + 단독 컴포넌트 23개)를 그대로 써볼 수 있다. 핵심 워크플로는 코드를 직접 짜는 게 아니라 — 마음에 드는 3D 장면을 고르고 **"Copy Prompt" 버튼으로 지시문을 복사해 클로드 코드·커서 같은 AI 코딩 도구에 그대로 붙여넣는 것**. 리액트로 직접 붙이는 npm 패키지 설치 경로도 있다.

## 💡 핵심 인사이트
- **프롬프트 우선, 코드는 선택**: 대부분의 유사 컴포넌트 라이브러리는 "코드를 복사해 붙이는" 방식인데, ThreeUI는 컴포넌트마다 **AI 도구용 프롬프트 복사 버튼**이 따로 있다. 코드를 읽을 줄 몰라도 AI 코딩 도구에 그대로 넘기면 구현된다는 게 차별점.
- **`Skill.md` 탭 — 에이전트 전용 지시문**: 컴포넌트 페이지마다 일반 사용자용 설명과 별개로 `Skill.md` 탭이 있어, 에이전트가 그대로 읽고 실행할 수 있는 지시문이 들어 있다. 패키지 설치 없이 "이 지시문대로 내 프로젝트에 만들어줘"만으로 구현 가능.
- **무료/유료가 한 화면에 섞여 있어 탐색 전략이 필요**: 전체 카탈로그 기준 무료 비율은 칸(카테고리)마다 크게 다르다 — 버튼·UI요소·글자효과·CSS는 100% 무료, 배경·Three.js는 약 1/3만 무료, 랜딩페이지·히어로·모션디자인은 거의 다 유료(무료 5개/63개뿐). 처음 진입 시 "랜딩페이지" 카테고리부터 열면 무료가 거의 없어 실망하기 쉬운 구조.
- **라이선스 구분**: 커뮤니티판의 앱 코드·컴포넌트 코드·ThreeUI 제작 이미지는 MIT, 포함된 오픈 폰트는 SIL OFL 1.1. 단, 사이트에서 불러오는 외부 미리보기 에셋은 저장소의 MIT 범위 밖이므로 별도 확인 필요.

## 🛠️ 적용법 가이드
**방법 A. 코딩 없이 프롬프트만 복사 (추천, 비개발자용)**
1. threeui.com에서 왼쪽 카테고리로 원하는 장면 계열을 고른다
2. 마음에 드는 장면 페이지에서 "Copy Prompt" 클릭 → 지시문 전체 복사
3. 클로드 코드·커서 등 AI 코딩 도구에 붙여넣고 "이 지시문대로 내 프로젝트에 넣어줘. 기존 파일은 건드리지 말고 새 파일로 만들어줘" 한 줄만 덧붙인다
4. 더 정확히 가려면 같은 페이지의 Usage 블록 → `Skill.md` 탭 내용도 함께 넘긴다
5. 색·속도·배치 등 세부 조정은 코드를 열지 않고 말로 지시 (예: "배경을 밝게, 움직임은 절반 속도로, 브랜드 컬러인 파랑 계열로")

**방법 B. 리액트 직접 설치 (개발자용)**
```
npm install @designcodeio/threeui
```
리액트 18~19, Three.js 0.149+, WebGL 지원 브라우저 필요.

## 💼 활용 예시
- **포트폴리오/제품 소개 페이지 첫 화면**: Predictive Arc·Structure Flow·Landscape 중 하나로 배경만 갈아도 인상이 확 바뀜.
- **"사용한 도구" 소개 줄**: Brand Orbs로 클로드·오픈AI·커서·피그마 등 23종 로고를 3D 구슬 회전으로 표시 — 로고 이미지를 따로 구할 필요 없음.
- **성과 지표 시각화**: Performance Gauges(속도계형 계기판)로 숫자를 표보다 눈에 잘 들어오게 표현.
- SR바이오텍 관련해서는 WAIPHA 파크골프 홈페이지처럼 3D/모션 배경이 필요한 랜딩페이지 작업 시, Three.js 코드를 처음부터 짜는 대신 이 방식으로 프롬프트만 넘겨 시간 절약 가능.

## ⚠️ 주의사항
- **프롬프트를 그대로 넘겨도 사이트에서 본 화면과 100% 동일하게 나오지 않을 수 있다** — 공식 지시문도 "화면 캡처가 아니라 원본 소스에서 다시 만들라"고 명시한 만큼, 한두 번의 재조정이 필요할 수 있음.
- 화면이 까맣게 나오는 흔한 원인 둘: ①프롬프트를 요약해서 잘라 넘긴 경우(전체를 그대로 넘길 것) ②브라우저가 WebGL을 지원하지 않는 경우.
- 모바일에서 3D 화면을 여러 개 동시에 띄우면 성능 부담이 큼 — 한 화면에 하나만 두고, "화면 밖으로 나가면 애니메이션 정지"를 AI 도구에 요청할 것.
- Pro·Beta 표시가 붙은 컴포넌트는 무료 저장소에 구현 코드가 없어 프롬프트만으로는 그대로 만들 수 없음(눈요기용).
- 페이지 상단에 회원가입 유도 배너가 있으나 실제 콘텐츠는 로그인 없이 전부 열람 가능했음.
