## 🎯 핵심 요약

실제로 5인 팀(SR바이오텍 HR팀) 세팅을 끝까지 완료해서 검증한 가이드. 준비물(Claude Pro/Max 구독, Anthropic API 키, 텔레그램, Windows CMD)만 갖추면 SSH 접속 → Docker 컨테이너 진입 → `hermes setup` → 텔레그램 봇 연결까지 순서대로 따라 한 번에 끝낼 수 있다. 핵심 함정은 **API 키 방식(OAuth 아님)**과 **claude-sonnet 모델(opus 아님)** 선택이다.

## 💡 핵심 인사이트

- **인증은 무조건 API 키(2번)**: OAuth(1번)를 선택하면 HTTP 400 오류가 난다 — Claude Pro/Max 구독이 있어도 API 호출 방식과는 호환되지 않기 때문.
- **모델은 무조건 Sonnet**: Opus는 정확도는 높지만 체감상 너무 느려서 실전 팀 사용에는 Sonnet이 성능-속도 균형점.
- **브라우저 터미널(ttyd)은 불안정**: 설정이 자꾸 리셋되는 문제가 있었음 → 반드시 Windows CMD로 SSH 접속 후 `docker exec`로 컨테이너 진입하는 방식을 표준으로 삼을 것.
- **게이트웨이는 기본적으로 foreground 실행**: CMD 창을 닫으면 봇이 죽는다. 서버 재시작 시에도 자동 복구되게 하려면 크론탭/systemd 서비스 등록이 필요.
- **한글 입력기(IME)가 토큰 붙여넣기 실패의 주범**: API 키·봇 토큰 붙여넣기 전 반드시 IME를 OFF로 해야 UnicodeDecodeError를 피할 수 있다.

## 🛠️ 적용법 가이드

**서버 접속 (Windows CMD)**:
```
ssh root@<서버IP>
```
`yes` → 비밀번호 입력(화면에 안 보이는 게 정상) → `root@<hostname>:~#` 뜨면 접속 완료.

**컨테이너 진입**:
```
docker exec -it hermes-agent-<인스턴스ID>-hermes-agent-1 /bin/bash
```

**초기 세팅 (컨테이너 안에서, 최초 1회)**:
```
hermes setup
```
1. Quick setup 선택
2. Anthropic (Claude models) 선택
3. **2번 (API key)** 선택 ← 반드시 2번, OAuth(1번) 금지
4. `sk-ant-...` API 키 붙여넣기 (우클릭 붙여넣기, IME OFF)
5. **claude-sonnet-4-6** 선택 ← opus 금지
6. TTS/터미널 백엔드: Keep current
7. Messaging: Set up now → 원하는 메신저 선택

**텔레그램 봇 연결**:
- `@BotFather`에게 `/newbot` → 봇 이름·username(`_bot`으로 끝나야 함) 지정 → 발급된 토큰 저장
- `@userinfobot`으로 본인 텔레그램 숫자 ID 확인
- 세팅 화면에 토큰 → ID 순서로 입력 → 홈 채널 `y` → Restart gateway `y`

**게이트웨이 실행**:
```
HERMES_ALLOW_ROOT_GATEWAY=1 hermes gateway restart
```

**게이트웨이 복구 절차 (안 될 때)**:
1. 컨테이너 재시작: `docker restart <컨테이너명>`
2. 30초 대기 후: `docker exec <컨테이너명> bash -c "HERMES_ALLOW_ROOT_GATEWAY=1 hermes gateway run --replace" &`
3. 텔레그램에서 `/start` 먼저 입력 후 말 걸기 (안 하면 "Chat not found" 오류)

**모델 변경 (나중에)**:
```
hermes setup model
```
→ `1. Use existing credentials` → `claude-sonnet-4-6`

## ⚠️ 주의사항

- SSH 접속이 안 되면 → 방화벽(Hostinger 대시보드 Security → Firewall)에서 22번 포트 확인
- HTTP 400 오류 → 인증 방식을 API 키(2번)로 재설정
- 봇이 응답 안 함 → 게이트웨이 재실행 명령어부터 시도
- 처음 접속 시 브라우저 보안 경고는 정상 — "고급 → 이동" 클릭하면 됨
- 헤르메스는 쓸수록 똑똑해지므로 2주 정도는 지켜볼 것
