## 🎯 핵심 요약
인스타그램 @alamin.8020ai가 정리한 카드뉴스로, **클라우드 구독형 AI 영상 생성 서비스(Runway·Sora·Kling·Pika 등) 없이 내 PC에서 무료 오픈소스 모델로 영상을 만드는 로컬 세팅 가이드**다. 핵심 도구는 원클릭 AI 앱 설치 프로그램 **Pinokio**와, 그 안에서 설치하는 영상 생성 엔진 **Wan2GP**(LTX-2, Wan, Hunyuan 등 오픈소스 영상 모델을 한 곳에서 구동).

## 🛠️ 요약 단계 (원문 카드뉴스 순서)
1. **준비물 확인**: PC/노트북, VRAM 6GB 이상(RTX 3060급 이상 권장), 여유 저장공간 20GB. 코딩 지식 불필요.
2. **Pinokio 설치**: pinokio.computer에서 다운로드 — "AI 도구용 앱스토어" 개념의 원클릭 설치 프로그램.
3. **Wan2GP 설치**: Pinokio 안에서 "Discover" → "Wan2GP" 검색 → 설치. Python/터미널/GitHub 클론 불필요.
4. **AI 모델 선택**: Wan2GP가 제공하는 오픈소스 모델 중 고르기 — LTX-2(소리 포함 생성, 무료판 Sora2/Veo3급), Wan(고품질 시네마틱), Hunyuan(사실적인 모션). 처음엔 가볍고 빠른 LTX-2 Distilled 버전 추천.
5. **첫 영상 생성**: Pinokio에서 Wan2GP 실행 → 브라우저에서 localhost:7860 접속 → 모델 선택 → 프롬프트 입력 → Generate → 2~5분 대기.

## 💰 원문에서 강조한 절감 효과
카드뉴스 원문은 이 로컬 세팅으로 대체 가능한 구독 비용을 다음과 같이 제시함(1차 정보, 재검증 안 함):
- Runway 연 $144, Sora 연 $240, Kling Pro 연 $192, Pika 연 $96 — 합계 연 $672 절감 주장
- 추가로 "생성 횟수 무제한 · 워터마크 없음 · 인터넷 불필요 · 데이터가 내 컴퓨터에만 남음"을 장점으로 제시

## ⚠️ 주의사항
- 비용 절감 수치는 카드뉴스 제작자의 마케팅성 주장이며, 실제 유료 서비스 요금표와 대조 검증하지 않았음.
- 로컬 GPU 성능에 따라 생성 시간·결과물 품질이 클라우드 서비스보다 떨어질 수 있음 — 원문에도 "2~5분 대기" 정도로만 언급, 결과물 퀄리티 비교는 없음.
- 게시물 댓글 중 일부는 "여기 소개된 것들보다 seedance 2.0이나 minimax H3가 더 낫고 무료다"라는 반박 의견도 있었음 — 도구 선택 시 참고.
