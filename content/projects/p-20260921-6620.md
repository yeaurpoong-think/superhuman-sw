## 🎁 이걸 하면 얻는 것
지금까지 AI 영상 하나 만들려면 Runway·Sora·Kling·Pika 같은 구독형 서비스에 월 몇 만원씩 내고, 그마저도 "생성 횟수 제한"에 걸렸을 것이다. 이 세팅을 끝내면 **내 컴퓨터 한 대가 곧 영상 생성 스튜디오가 된다** — 구독료 0원, 생성 횟수 무제한, 워터마크 없음, 인터넷 끊겨도 작동, 만든 영상은 내 하드디스크에만 남는다. 대신 클라우드보다 느리고(내 GPU 성능만큼만 나온다), 처음 설치에 최소 20~30분 + 모델 다운로드 대기 시간이 든다. "구독은 부담스럽지만 가끔 영상 실험을 해보고 싶다"는 사람에게 맞는 세팅이다.

## 🎯 핵심 요약
**Pinokio**(AI 앱 전용 원클릭 설치 프로그램, Windows/Mac/Linux 지원)를 깔고, 그 안에서 **Wan2GP**(정식 명칭 WanGP, 개발자 deepbeepmeep, GitHub 스타 9.6천 개)라는 오픈소스 영상 생성 엔진을 설치하면 터미널 명령어 한 줄 없이 브라우저 화면(`localhost:7860`)에서 텍스트→영상 생성을 할 수 있다. **최소 사양은 GPU VRAM 6GB + 시스템 RAM 16GB**이며, 이 조건이면 5초 영상을 5~6GB VRAM으로 만들 수 있다(WanGP 공식 문서 기준). 지원 모델은 Wan 2.1/2.2, LTX-2, Hunyuan Video, MiniMax H3 등 10종 이상.

## 💡 핵심 인사이트
- **"코딩 몰라도 된다"는 말은 절반만 맞다** — Pinokio 앱 자체는 클릭만 하면 되지만, 뒤에서는 Python 가상환경·PyTorch·CUDA 드라이버가 자동으로 설치된다. 즉 "터미널을 직접 칠 일은 없지만, 설치 도중 뜨는 진행 로그(터미널 창처럼 생긴 화면)를 보고 기다릴 일은 있다"는 게 정확한 표현이다.
- **최소 요구사양은 광고 문구가 아니라 실측치다** — WanGP 공식 저장소는 "5초(124프레임) 영상은 5~6GB VRAM, 15초 영상은 8~9GB VRAM(해상도 832x480 기준)"이라고 구체적으로 밝힌다. 즉 노트북에 내장 그래픽만 있다면(GPU 없음) 이 세팅은 사실상 불가능하고, RTX 3060(12GB) 이상이면 여유 있게 돌아간다.
- **인스타 카드뉴스가 강조한 "연 672달러 절감" 주장은 재검증 안 된 마케팅 수치다** — Runway 연 $144·Sora 연 $240·Kling Pro 연 $192·Pika 연 $96 합산인데, 실제 각 서비스 최신 요금제와 대조 확인은 하지 않았다. "무료"라는 결론 자체는 맞지만(Wan2GP는 완전 무료 오픈소스), 정확한 절감액은 사람마다 원래 쓰던 구독 조합에 따라 다르다.
- **Pinokio 안에도 "공식 버전"과 "커뮤니티 버전"이 따로 있다** — Wan2GP 공식 GitHub 문서는 "Pinokio 공식 설치보다 Morpheus가 만든 커뮤니티 스크립트(`wan2gp` 또는 AMD GPU면 `wan2gp-amd`)를 쓰는 걸 권장한다"고 명시한다. 아래 따라하는 법은 이 권장 버전 기준이다.
- **댓글 반박도 참고할 가치가 있다** — 원문 게시물 댓글 중 "여기 소개된 것보다 Seedance 2.0이나 MiniMax H3가 더 낫고 무료다"는 의견이 있었다. Wan2GP는 실제로 MiniMax H3도 함께 지원하므로, 설치 후 모델 선택 단계에서 H3도 시도해볼 수 있다.

## 🛠️ 따라 하는 법 (단계별 가이드)

> ⚠️ **준비물부터 확인 (여기서 막히면 이후 단계 전부 무의미하다)**
> - **GPU(그래픽카드)**: NVIDIA 그래픽카드가 있어야 한다. "그래픽카드가 뭔지 모르겠다" → 내 컴퓨터가 게임을 돌릴 수 있는 데스크톱/게이밍 노트북이면 있을 가능성이 높고, 사무용 노트북(맥북 포함 내장 그래픽만 있는 모델)이면 없을 가능성이 높다. 확인법은 STEP 0 참고.
> - **VRAM(그래픽카드 전용 메모리) 최소 6GB** — RTX 3060 이상 권장. GTX 10XX대(구형)도 되지만 속도가 느리다.
> - **시스템 RAM 16GB 이상**
> - **여유 저장공간 20~30GB 이상** (모델 파일 하나가 수 GB짜리다)
> - **Mac(애플 실리콘 M1~M4)도 지원되지만 느리다** — Pinokio 설치 스크립트가 Mac은 VRAM 체크를 건너뛰긴 하지만, 실제로는 NVIDIA GPU 전용 최적화가 많아 M시리즈 맥에서는 체감 속도가 크게 떨어진다는 게 커뮤니티 중론이다. 진지하게 쓸 거면 NVIDIA 그래픽카드가 달린 Windows/Linux PC를 권장한다.

### STEP 0. 내 컴퓨터에 쓸만한 그래픽카드가 있는지 확인한다
- **Windows**: 키보드에서 `Ctrl + Shift + Esc`를 눌러 작업 관리자를 연다 → 상단 탭에서 "성능" 클릭 → 왼쪽 목록에서 "GPU 0"(또는 GPU 1)을 클릭 → 화면 우측 상단에 그래픽카드 이름(예: "NVIDIA GeForce RTX 3060")과 "전용 GPU 메모리" 수치(=VRAM)가 보인다. NVIDIA 이름이 없고 Intel/AMD 내장 그래픽만 보이면 이 세팅은 어렵다.
- **확인 결과 NVIDIA 그래픽카드 + VRAM 6GB 이상이면 다음 단계로.**

### STEP 1. Pinokio 설치
1. 브라우저에서 https://desktop.pinokio.co 접속
2. 화면 상단 "Download" 버튼 클릭 → 자신의 운영체제(Windows/Mac/Linux)에 맞는 설치 파일이 자동으로 받아진다
3. 다운로드된 설치 파일을 실행한다 (Windows는 `.exe` 더블클릭, Mac은 `.dmg` 더블클릭 후 Applications 폴더로 드래그)
4. **확인 지점**: 설치가 끝나면 바탕화면 또는 앱 목록에 "Pinokio" 아이콘이 생기고, 실행하면 검은 배경에 다양한 AI 앱 카드가 격자로 나열된 화면(=Pinokio 홈 화면)이 뜬다.

### STEP 2. Wan2GP 앱 찾아서 설치
1. Pinokio 실행 후 화면 상단 또는 좌측의 검색창(돋보기 아이콘)을 클릭
2. "wan2gp" 또는 "wan"이라고 검색
3. 검색 결과에서 **"Wan2GP" (제작자 표시: `github.com/pinokiofactory/wan`, "Featured" 배지 있음)**를 선택한다 — 이게 공식 저장소가 권장하는 커뮤니티 최적화 버전이다. 이름이 비슷한 다른 항목(`6Morpheus6/wan2gp` 등)도 있지만 위 것을 우선 선택한다.
4. 앱 상세 화면에서 **"Install"** 버튼 클릭
5. **확인 지점**: 화면이 검은 터미널 로그 창으로 바뀌면서 글자가 스크롤되기 시작한다 — 이게 정상이다. 내부적으로 파이썬 가상환경 생성 → PyTorch(그래픽 연산 라이브러리) 설치 → 필요한 패키지 설치를 자동으로 진행하는 중이다. **인터넷 속도에 따라 10~30분 걸릴 수 있다**, 로그가 멈춘 것처럼 보여도 창을 닫지 말고 기다린다.
6. 로그 마지막 줄에 **"Installation completed"**라는 메시지가 뜨면 설치 완료.

### STEP 3. 첫 실행
1. Pinokio에서 방금 설치한 Wan2GP 앱으로 이동하면 화면에 **"Start"** 버튼이 보인다. 클릭한다.
2. 다시 터미널 로그 화면이 뜨며 서버가 켜지는 과정이 보인다.
3. **확인 지점**: 로그에 서버 주소(보통 `http://localhost:7860` 형태)가 뜨고, 화면 상단 메뉴에 **"Open Web UI"**라는 버튼이 새로 나타난다. 이 버튼이 안 뜨면 아직 서버가 켜지는 중이니 조금 더 기다린다.
4. **"Open Web UI"** 클릭 → 기본 브라우저가 열리며 Wan2GP의 실제 작업 화면(모델 선택 드롭다운, 프롬프트 입력창, Generate 버튼이 있는 화면)이 뜬다.

### STEP 4. 첫 모델 선택 및 다운로드
1. 화면 상단 모델 선택 드롭다운에서 **"Wan 2.1 T2V 1.3B"**를 고른다 — 공식 문서가 "가장 빠르고 VRAM을 가장 적게 쓰는(6GB) 입문용 모델"로 추천하는 모델이다.
2. 처음 선택하면 해당 모델 파일이 자동으로 다운로드된다(수 GB, 인터넷 속도에 따라 몇 분~십수 분).
3. **확인 지점**: 화면 상단에 다운로드 진행률 바가 뜨고, 100%가 되면 프롬프트 입력창이 활성화(클릭 가능)된다.

### STEP 5. 첫 영상 생성
1. 프롬프트 입력창에 다음처럼 영어 또는 한글로 장면을 구체적으로 적는다 (예시): `A cat walking in a garden, sunny day, realistic` (정원을 걷는 고양이, 맑은 날, 사실적으로)
2. 화면 하단(또는 고급 설정 체크박스를 켜면 나오는) **Frames(프레임 수)**는 처음엔 기본값(49 = 약 2초) 그대로 둔다
3. **Steps(생성 단계 수)**도 기본값(20 전후, "속도와 품질의 균형")을 그대로 둔다 — 나중에 결과물이 흐릿하면 25~30으로 올려본다
4. 화면의 **"Generate"** 버튼 클릭
5. **확인 지점**: 화면에 진행률 표시(퍼센트 또는 진행 바)가 나타난다. 6GB급 GPU 기준 5초 영상은 대략 몇 분 내로 끝난다.
6. 완료되면 화면 하단 갤러리 영역에 방금 만든 영상이 썸네일로 나타난다 — 클릭하면 재생, 다운로드 아이콘으로 내 컴퓨터에 파일 저장 가능.

## 💼 활용 예시
- **BeauT오빠(뷰티 인스타 자동화) 콘텐츠 실험**: 클라우드 영상 생성 구독료 없이 릴스용 배경 영상(예: 스킨케어 제품이 놓인 테이블을 천천히 비추는 장면) 시제품을 무제한으로 뽑아보고, 마음에 드는 결과만 골라 실제 릴스에 활용 — 초기 콘텐츠 실험 단계에서 유료 툴 비용을 아낄 수 있다.
- **서고(superhuman-sw) 카드 제작 실습용**: 이번 카드처럼 "직접 설치→생성까지 해보고" 그 과정 자체를 다시 튜토리얼 카드로 만드는 연습 대상으로 적합 — 실제로 실행(`executed_at`)까지 채우면 다음 서고 카드에 "설치하며 실제로 막혔던 지점"을 추가할 수 있다.

## ⚠️ 주의사항
- **비용 절감 수치(연 $672)는 카드뉴스 제작자의 마케팅성 주장이며 검증하지 않았다** — 실제 절감액은 원래 어떤 구독을 얼마나 쓰고 있었는지에 따라 다르다.
- **"무료·무제한"이지만 "품질 동일"은 아니다** — 로컬 GPU 성능에 따라 생성 시간·해상도·디테일이 클라우드 서비스(Sora, Kling 등)보다 떨어질 수 있다. WanGP 자체 문서도 "GPU Poor를 위한" 도구임을 명시한다.
- **NVIDIA 그래픽카드가 없으면(맥북 에어/프로 내장 그래픽, 사무용 노트북 등) 사실상 설치해도 매우 느리거나 작동하지 않는다** — 진행 전 STEP 0에서 그래픽카드부터 확인할 것.
- **설치 중 자주 나오는 에러**(Pinokio 커뮤니티 게시판 기준, 2026.09): `CUDA not compiled`(그래픽카드 드라이버 문제), `ModuleNotFoundError: No module named 'numpy'`, `DLL load failed while importing _regex`(Windows 보안 정책 차단) — 이런 에러가 뜨면 먼저 그래픽카드 드라이버를 최신 버전으로 업데이트하고 재설치를 시도한다.
- **댓글 반박(Seedance 2.0/MiniMax H3가 더 낫다는 의견)은 1차 확인 안 된 개인 의견** — 다만 Wan2GP 자체가 MiniMax H3도 지원하므로 설치 후 비교해보고 판단하면 된다.
