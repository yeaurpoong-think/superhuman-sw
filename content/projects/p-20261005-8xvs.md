## 🎯 핵심 요약

**MiniMax H3**는 영상과 소리를 **한 번에** 만드는 AI 영상 모델이다. 지금까지 영상 AI는 화면만 만들고 소리는 따로 구해 편집 프로그램에서 붙여야 했는데, H3는 한 번 생성할 때 **효과음·대사·배경음까지 같이** 뽑아 준다(4~15초, 24FPS, 32kHz 스테레오). 한국어 대사도 공식 지원 11개 언어에 들어가 립싱크가 맞는다. 공개 2개월 만에 GitHub ⭐9.5천, 허깅페이스 다운로드 350만 회를 넘길 만큼 화제다. 공식 웹앱 또는 무료 체험판에서 설치 없이 바로 써볼 수 있고, **결과는 프롬프트를 '장면·인물·카메라·소리' 네 덩어리로 쓰느냐에서 갈린다.** 단, **한국은 모델 라이선스 적용 지역에서 빠져 있어서**, 업무에 쓰려면 공식 서비스(웹앱·API) 경로를 쓰고 이용 조건을 먼저 확인해야 한다.

## 💡 핵심 인사이트

- **'소리 없는 영상 AI' 시대가 끝나간다.** 릴스·숏폼은 소리가 절반인데, 지금까지는 AI 영상을 뽑아도 사운드 작업이 남았다. H3는 화면과 소리를 한 모델이 함께 이해하고 생성하는 '옴니 모델'이라 후반 작업 단계가 하나 줄어든다.
- **한국어 대사 + 립싱크.** 지원 언어 11개(아랍어·중국어·영어·프랑스어·독일어·이탈리아어·일본어·한국어·포르투갈어·러시아어·스페인어) 안에 한국어가 있다. 국내용 숏폼 광고나 제품 소개 영상의 초안으로 쓸 수 있다.
- **넣을 수 있는 재료가 넓다.** 두 가지 모드가 있다.
  - **FL2VA:** 글만 넣거나, 첫 장면·끝 장면 이미지를 지정해서 영상을 만든다.
  - **Ref2VA:** 참고 이미지(최대 9장)·영상·음성을 넣어 특정 인물·목소리·분위기를 유지한다. 제품이나 모델 일관성이 필요할 때 쓴다.
- **결과 품질은 모델보다 프롬프트가 좌우한다.** 소리까지 만드는 모델이라 화면만 적으면 소리 자리를 모델이 아무렇게나 채운다. "멋있게", "감성적으로" 같은 형용사 대신 **눈에 보이는 것과 귀에 들리는 것만** 적는 게 원칙이다.
- **공식 '프롬프트 작성 스킬'이 있다.** MiniMax가 직접 Claude Code용 스킬(`h3-prompt-writing`)을 배포한다. 한 번 설치하면 AI가 공식 프롬프트 규칙대로 H3용 프롬프트를 써 준다.

## 🛠️ 적용법 가이드

**1단계 · 브라우저에서 첫 영상 만들기 (설치 없음, 5분)**
- **공식 웹앱:** [hailuoai.video](https://hailuoai.video/tools/minimax-h3)
- **무료 체험판 (허깅페이스 Space, 하루 사용량 제한·대기열 있음):**
  - [multimodalart/minimax-h3](https://huggingface.co/spaces/multimodalart/minimax-h3)
  - [mrfakename/minimax-h3-ultra-fast](https://huggingface.co/spaces/mrfakename/minimax-h3-ultra-fast)
- 처음엔 길이를 **5초**로 짧게 잡고 여러 번 돌리며 감을 잡는다.
- 테스트용 예시 프롬프트(화면+소리):
  ```
  A rainy night street in Seoul, neon signs reflected on wet asphalt. A woman in a beige coat opens a black umbrella and walks toward the camera. The camera slowly pushes in at eye level. Sound of heavy rain on the umbrella, distant traffic, and footsteps splashing through a puddle.
  ```
  재생했을 때 빗소리와 발소리가 같이 들리면 성공이다.

**2단계 · 프롬프트는 네 덩어리로 쓴다 (핵심)**

| 덩어리 | 적을 것 | 예시 |
|---|---|---|
| 장면 | 어디에 무엇이 있는지 | 창가 자리 카페, 오후 햇빛 |
| 인물 | 나이대·옷·표정·동작 | 베이지 코트의 30대 여성이 컵을 내려놓는다 |
| 카메라 | 다가가기·돌기·고정 | 정면에서 천천히 다가간다 |
| 소리 | 효과음·대사·배경음 | 창밖 빗소리, 잔이 접시에 닿는 소리 |

- 요청한 길이와 묘사한 내용의 양을 맞춘다. 5초 영상에 장면 다섯 개를 넣지 않는다.
- 참고 자료는 이름표로 부른다: `<Picture 1>`, `<Video 1>`, `<Audio 1>`. 문단이 바뀌어도 같은 이름표를 유지한다.
- 한국어 대사는 따옴표로 감싸고 언어를 명시한다. 15초 안에 들어가도록 두세 문장 이내로 쓴다.

**3단계 · AI에게 프롬프트 규칙 통째로 설치하기 (선택, Claude Code 사용자)**
```bash
npx skills add https://github.com/MiniMax-AI/MiniMax-H3 --skill h3-prompt-writing
```
- 설치되면 `.claude/skills/h3-prompt-writing/references/`에 공식 가이드 2개가 생긴다.
  - `base-en.txt`: 글·키프레임 모드용
  - `ref-en.txt`: 참고 자료 모드(Ref2VA)용
- 그다음엔 이렇게 시키면 된다: "h3-prompt-writing 스킬을 따라서 ○○을 5초짜리 H3 프롬프트로 만들어 줘. 화면 설명과 소리 설명을 모두 넣어 줘."

**4단계 · 내 PC에서 돌리기 (선택, 고사양 전용)**
- 엔비디아 그래픽카드가 필수다. 원본 가이드 기준으로 최적화 배포판에서도 5초 영상에 VRAM 56GB, 15초에 89GB가 필요하다. 사실상 일반 PC로는 불가하다.
- 원본 가중치는 한 모드만 받아도 140GB가 넘는다. 해보려면 원클릭 설치 도구 **Pinokio → Wan2GP**(H3 공식 지원)를 쓴다. 생성 단계는 최소 15~20 이상으로 잡는다.

## 💼 활용 예시

- **숏폼 광고 소재 초안:** 제품 사용 장면에 효과음(펌프 누르는 소리, 물 떨어지는 소리)과 한국어 내레이션까지 한 번에 뽑아 A/B 테스트용 소재를 빠르게 여러 개 만든다.
- **제품·모델 일관성 영상:** Ref2VA에 제품 사진과 모델 이미지를 참고로 넣어, 같은 제품과 같은 인물이 나오는 시리즈 영상을 만든다.
- **콘텐츠 기획 프리비즈:** 촬영 전에 콘티를 영상과 소리로 미리 뽑아 보고, 촬영팀이나 대행사와 방향을 맞추는 시안으로 쓴다.

## ⚠️ 주의사항

- **⚠️ 라이선스 — 한국이 적용 지역에서 빠져 있다 (가장 중요).** 모델 가중치에 붙은 *MiniMax H3 Community License*는 적용 지역을 "전 세계에서 **EU·영국·한국·미국을 제외**"로 정하고 있다. 또 적용 지역 밖에서는 모델과 **결과물(Output)** 사용도 허가하지 않는다고 적혀 있다(라이선스 원문 직접 확인). 그래서 한국에서 가중치를 직접 받아 돌리거나, 가중치 기반 무료 체험판으로 만든 영상을 업무·광고에 쓰는 것은 이 라이선스로는 허가되지 않는다.
  - 업무용으로는 **공식 웹앱(hailuoai)·공식 API** 경로를 쓰고, 해당 서비스 이용약관과 상업적 이용 조건을 따로 확인해야 한다.
  - 라이선스상 한국에서 쓰려면 MiniMax에 별도 라이선스를 문의할 수 있다고 안내돼 있다.
- **비공식 배포처를 조심한다.** 이름이 비슷한 가짜 저장소가 있다. 모델은 `MiniMax-AI/MiniMax-H3`(GitHub)나 `MiniMaxAI/MiniMax-H3`(허깅페이스)에서만 받는다. `.exe`, `.7z` 설치 파일을 받으라는 곳은 공식 배포처가 아니다.
- **자동 검수가 있다.** 공식 서비스는 불법이거나 타인의 권리를 침해하는 요청을 차단할 수 있다. 실존 인물 얼굴이나 목소리, 타 브랜드를 다룰 때 특히 주의한다.
- **무료 체험판은 불안정하다.** 공용 GPU라 대기열이 생기고 하루 사용량이 제한된다.
- **자주 막히는 곳**
  - 소리가 안 나올 때: 프롬프트에 소리 설명이 없는 경우가 대부분이다.
  - 결과가 매번 다를 때: 네 덩어리를 다 적으면 결과가 안정된다.
  - 메모리 부족 오류: 5초·480p로 먼저 만든다.
- 팩트체크(2026.10.05 기준)
  - GitHub `MiniMax-AI/MiniMax-H3`: ⭐9,556, 2026.07.30 공개

  - 출력 사양·지원 언어·모드·설치 명령은 공식 README와 일치
  - 체험판 Space 2곳 모두 RUNNING
  - Wan2GP의 H3 지원도 공식 README에서 확인
