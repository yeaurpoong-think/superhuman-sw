## 🎯 핵심 요약

**open-slide**는 "말로 주문하면 AI가 PPT를 코드로 짜 주는" 오픈소스 슬라이드 도구다. 2.0 버전(2026.09.26 릴리스)부터 **AI가 초안을 만들고, 마무리 손질은 사람이 화면에서 직접 하는 구조**로 바뀌었다. 요소를 끌어서 옮기고, 늘리고, 돌리는 비주얼 편집기와 더블클릭 글자 수정이 추가됐고, 완성본은 **글상자·도형이 살아 있는 PPTX**로 내보내져 파워포인트에서도 계속 고칠 수 있다. 무료(MIT)이고 명령어 한 줄로 시작한다.

## 💡 핵심 인사이트

- **AI PPT의 진짜 문제는 '마지막 손질'이었다.** 지금까지 AI로 만든 발표 자료는 글자 하나, 위치 조금만 바꾸려 해도 AI에게 다시 요청해야 했고, 회사에서 쓰는 파워포인트 파일로 옮기기도 어려웠다. 2.0은 이 지점을 정면으로 해결했다 — "초안은 AI, 마무리는 사람".
- **'이미지 PPT'가 아니라 '편집 가능한 PPTX'.** 내보내기 시 글자는 글상자로, 도형은 도형으로, 이미지는 이미지로 변환된다. 즉 받은 사람이 파워포인트에서 열어 각 요소를 그대로 고칠 수 있다(변환은 브라우저 안에서 처리, 서버 불필요). PDF와 웹페이지(정적 HTML)로도 내보낼 수 있다.
- **화면에서 고친 내용이 원본 코드에 그대로 저장된다.** 더블클릭으로 글자를 고치고, 떠 있는 도구 막대에서 크기·굵기·기울임·색·정렬을 바꾸면 슬라이드 원본 코드에 반영된다. 되돌리기·다시하기도 지원.
- **"메모 남기기 → 한 번에 반영" 루프.** 고칠 곳을 클릭해 "제목 줄여줘" 같은 메모를 남기면 메모가 코드에 표시로 쌓이고, 에이전트에게 `/apply-comments`를 실행시키면 모든 메모를 반영한 뒤 표시를 지운다. 여러 군데를 한 번에 손볼 때 효율적이다.
- **에이전트 전용 설계.** Claude Code, Codex, Cursor 등 어떤 코딩 에이전트와도 쓸 수 있고, 프로젝트를 만들면 `/create-slide`(주제·디자인 톤·장수·텍스트 밀도·모션 여부 4가지를 먼저 물어본 뒤 덱 전체 작성) 스킬이 기본 탑재된다.

## 🛠️ 적용법 가이드

**준비물:** Node.js 20.19 이상(또는 22.12 이상), Claude Code 같은 코딩 에이전트, pnpm

1. **프로젝트 만들기** — 터미널에서:
   ```bash
   npx @open-slide/cli init my-slide
   cd my-slide
   pnpm dev
   ```
2. **덱 초안 주문** — 그 폴더에서 Claude Code를 켜고 `/create-slide`를 실행하거나 "○○ 주제로 10장짜리 발표자료 만들어줘"라고 말한다. 에이전트가 주제·톤·장수·텍스트 밀도를 묻고 덱을 작성한다.
3. **화면에서 직접 손질** — 브라우저(개발 서버)에서 요소를 드래그로 옮기고·늘리고·돌리고, 글자는 더블클릭으로 바로 수정한다.
4. **큰 수정은 메모로** — 고칠 곳을 클릭해 메모("이 부분 빨간색으로", "제목 짧게")를 남긴 뒤, 에이전트에게 `/apply-comments` 실행.
5. **내보내기** — 편집 가능한 PPTX, 인쇄용 PDF, 정적 HTML 중 선택. 발표는 내장 프레젠터 모드(다음 장 미리보기·발표자 노트·타이머)로도 가능.

## 💼 활용 예시

- **사내 교육·온보딩 자료** — AI로 초안을 빠르게 뽑고, 회사 템플릿에 맞춰 화면에서 직접 다듬은 뒤 PPTX로 공유. 받은 사람이 파워포인트에서 바로 수정 가능.
- **경영진 보고 장표** — 리서치 문서(예: 경쟁사 분석)를 넣고 "핵심 5장으로 요약 장표"를 주문 → 수치·문구만 사람이 최종 확인·수정.
- **반복 장표 자동화** — 주간·월간 리포트처럼 구조가 같은 덱을 코드로 만들어 두고, 데이터만 바꿔 매번 재생성 후 PPTX 배포.

## ⚠️ 주의사항

- **완전 비개발자용은 아니다.** 터미널 명령어, Node.js 설치, 코딩 에이전트(Claude Code 등) 사용이 전제다. 처음엔 설치를 도와줄 사람이 있으면 좋다.
- **슬라이드는 React 코드로 만들어진다.** 1920×1080 고정 캔버스 기반이라 자유도는 높지만, 아주 복잡한 레이아웃은 에이전트에게 여러 번 수정을 요청해야 할 수 있다.
- **PPTX 변환 결과는 원본과 100% 같지 않을 수 있다.** 애니메이션·특수 효과는 파워포인트에서 다르게 보일 수 있으니, 중요 자료는 내보낸 뒤 파워포인트에서 한 번 확인할 것.
- 원본 게시물의 "설치부터 PPTX 내보내기까지 가이드"는 댓글→DM으로 받는 구조라 확보하지 못했다. 위 설치·사용법은 **GitHub 공식 README와 패키지 정보로 직접 확인한 내용**이다.
