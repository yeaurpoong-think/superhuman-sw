## 🎯 핵심 요약

@ukwaehan_0sajang(Verified) 계정 릴스. "클로드(Claude) 코워크로 메타(Meta) 광고를 컨트롤한다"는 주제를 내세우지만, 영상 자체에는 실행 방법이 전혀 노출되지 않고 **"댓글에 '메타' 남기면 DM으로 전달"** 하는 리드젠(lead-gen) 구조로 운영된다. 2026.09 기준 좋아요 2,920·댓글 5,894·리포스트 672 — 댓글 수가 유독 높은 건 인게이지먼트가 아니라 유도 전략의 결과.

## 💡 핵심 인사이트

- **주제와 실행 내용이 분리된 콘텐츠 구조**: 캡션 "클로드 코워크로 메타광고 컨트롤하기! 제가 전부 정리해놨습니다:) 📩필요하신 분들은 댓글에 '메타' 남겨주세요"만 노출되고, 실제 워크플로(어떤 광고 지표를 클로드에 물어보는지, 어떤 MCP/API를 쓰는지)는 영상에 전혀 나오지 않음 — 정보 자체가 상품화된 구조
- **댓글 5,894 vs 좋아요 2,920 — 통상 비율의 역전**: 일반 콘텐츠는 좋아요가 댓글보다 훨씬 많은데, 이 릴스는 댓글이 좋아요의 2배 이상 — "댓글=키워드 남기면 DM" 유도가 실제로 작동한다는 증거이자, 참여율 지표로 오독하면 안 되는 사례

## 🛠️ 적용법 가이드

- 이 릴스에서 배울 건 방법론이 아니라 **콘텐츠 포맷 자체** — SR바이오텍이나 BeauT오빠 계정에서 "정보를 숨기고 댓글 유도로 리드를 모으는" 구조를 실험해볼 근거 사례로 참고 가능
- "Claude로 메타 광고를 관리한다"는 주제 자체는 실제로 존재하는 워크플로일 가능성이 높음(Meta Ads API + Claude MCP 조합) — 직접 조사해서 별도 카드로 만들 가치는 있음

## 💼 활용 예시

## ⚠️ 주의사항

- 실제 방법론은 **미확인** — DM으로만 전달되는 구조라 이 카드의 정보만으로는 재현 불가능. "Claude + Meta 광고" 자체를 알고 싶다면 별도로 공식 Meta Marketing API + MCP 연동 사례를 조사해야 함
- 댓글수·좋아요수는 인스타그램 화면에서 직접 확인한 1차 수치(2026.09 시점 스냅샷), 이후 변동 가능
