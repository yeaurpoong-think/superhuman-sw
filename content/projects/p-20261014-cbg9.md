## 🎯 핵심 요약

**REA(Reverse Engineer Anything)**는 Claude Code 같은 AI 에이전트에 붙여 쓰는 **MCP 도구**다. 소스 코드가 없는 앱도 안쪽을 직접 들여다보고, "이 기능이 어떻게 돌아가는지"를 **근거와 함께** 설명한 뒤, 같은 원리로 내 프로젝트용 기능을 짜고 테스트까지 돌린다. 한 줄로 말하면 **"남의 앱에서 본 좋은 기능을, AI가 뜯어보고 원리를 알려주는 도구"**다. MIT 라이선스 오픈소스라 도구 자체는 무료이고, GitHub ⭐20.7만으로 지금 가장 빠르게 뜨는 개발 도구 중 하나다.

## 💡 핵심 인사이트

- **쓰는 법은 문장 하나다.** 설치(`npx rea-agents setup`) 후 에이전트에게 "OO 앱의 OO 기능이 어떻게 돌아가는지 근거와 함께 알려주고, 내 프로젝트에 비슷하게 만들어줘"라고 말하면 된다.
- **"추측"이 아니라 "증거"를 준다.** 결과마다 어떤 코드·문자열·호출 경로를 보고 그렇게 판단했는지, 그리고 모르는 부분(한계)까지 같이 돌려준다. README 기준 분석은 로컬에서 돌고, 결과만 에이전트(모델)로 넘어간다.
- **분석 범위가 넓다.** 데스크톱 앱(네이티브 바이너리), 자바스크립트·일렉트론 앱(노션·슬랙 같은 데스크톱 앱 구조), 웹사이트, 안드로이드 APK, .NET, 네트워크 캡처까지 다룬다. 웹사이트·자바스크립트 앱은 별도 무거운 분석 프로그램 없이도 된다.
- **공식 사례가 상징적이다.** README 쇼케이스에 "노션 데스크톱 앱의 클립보드(복사·붙여넣기) 처리 경로 추적"이 있다. 우리가 매일 쓰는 앱의 기능도 이렇게 뜯어볼 수 있다는 뜻이다.
- **"모든 소프트웨어가 사실상 오픈소스가 된다."** 원본 릴스는 리플릿(Replit) CEO의 이 발언을 인용한다. 기능을 베끼는 비용이 0에 가까워지면, 기능 자체보다 **브랜드·데이터·고객 경험**이 경쟁력이 된다는 신호로 읽힌다.

## 🛠️ 어떻게 쓰나

1. Node.js 22 이상 설치
2. 터미널에서 실행

   ```bash
   npx rea-agents setup
   ```

   쓰는 에이전트(Claude Code, Codex, Cursor, Gemini CLI 등)를 고르고 변경 사항을 승인한 뒤 에이전트를 재시작한다.
3. 에이전트에게 요청 (README 공식 예시)

   ```text
   Understand how search works in the Notes app, show me the evidence, and build a
   similar feature for my project.
   ```

   Notes와 search 자리에 원하는 앱과 기능을 넣으면 된다. 한국어 예시: "○○ 앱의 ○○ 기능이 어떻게 동작하는지 근거와 함께 설명하고, 내 프로젝트에 비슷한 기능을 만들어 테스트까지 해줘."
4. 업데이트가 잦다 → `npx rea-agents@latest setup`으로 갱신

## 💼 어디에 쓸 수 있나

- **내 프로젝트(trip-planner 등)에 넣고 싶은 기능 원리 파악:** 잘 만든 앱의 동작 방식을 이해하고 직접 구현
- **사내 도구 연동 조사:** 우리가 권한을 가진 사내 앱·자사 웹사이트가 어떻게 데이터를 주고받는지 확인
- **경쟁사 웹사이트 구조 이해:** 공개 웹페이지의 구조·스크립트 수준 관찰 (단, 약관 확인 필수)

## ⚠️ 주의사항

- **쓸 수 있는 범위:** README 면책 조항은 "합법적 연구·교육·호환성·내가 소유하거나 분석 허가를 받은 소프트웨어"로 한정한다. 남의 앱을 뜯어 그대로 복제·배포하면 저작권·이용약관 위반이 될 수 있다. 원본 릴스도 "권리가 있거나 허용된 범위에서만"을 강조한다.
- **유료 분석 툴은 별도:** 네이티브 앱 심층 분석은 Hopper·Ghidra·IDA 중 하나가 필요하다. Ghidra는 무료지만 IDA Pro·Hopper는 상용이고, REA는 이 툴들의 라이선스를 주지 않는다.
- **사칭 저장소 주의:** 별을 비슷하게 단 복제 저장소(`NabilRFG12/Reverse-Engineer-anything` 등)가 이미 있다. README도 공식 출처는 `morluto/rea`, `rea.tools`, npm `rea-agents`뿐이라고 못 박는다. 다른 곳에서 받지 말 것.
- **회사 정보:** 분석은 로컬이지만 결과는 AI 모델 쪽으로 넘어간다. 회사 내부 앱을 분석할 땐 모델 제공사 데이터 정책을 확인한다.
- **직접 확인:** GitHub API — ⭐207,004 / 포크 50,491 / MIT / 생성 2026-04-14 / 최신 릴리스 rea-agents 6.4.0(2026-10-11). README의 설치 명령, 지원 대상, 면책 조항.
- **원문 인용, 재검증 못 함:** 리플릿 CEO의 "곧 모든 소프트웨어가 사실상 오픈소스가 될 것" 발언 원문·시점.
- 원본 릴스의 "댓글 남기면 정리본 DM"은 확보하지 않았다. 설치법과 프롬프트는 GitHub 공식 README 기준으로 대체했다.
