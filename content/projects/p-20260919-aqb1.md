## 🎯 핵심 요약
BeauT오빠 블로그(105편 발행 완료)를 소재로, 인스타그램 카드뉴스를 자동 제작하는 파이프라인을 하루 만에 기획·구현·재설계까지 완료했다. 계정 [@beaut.oppa](https://www.instagram.com/beaut.oppa/)로 실제 발행 중이며, 코드는 [GitHub](https://github.com/yeaurpoong-think/Insta-mag.auto)에 공개돼 있다.

## 💡 핵심 인사이트
- **원천 재사용 구조**: 새 소재를 조사하는 대신, 이미 논문 검증까지 끝난 자체 블로그 글을 카드뉴스로 재해석한다. 신뢰도가 검증된 콘텐츠를 다른 포맷으로 재가공하는 전략.
- **당일 실패→재설계 사이클**: v1(저채도 베이지+도형)이 "밋밋하다"는 피드백을 받자 그날 안에 참고 계정(@kodeok.kr) 문법을 분석해 v2로 완전히 재설계했다.
- **렌더러도 당일 전환**: Figma MCP로 노드를 직접 만들려다 호출 제한에 걸려 8장 중 3장을 검수 못하는 문제가 생기자, HTML→PNG(Playwright) 렌더링으로 즉시 바꿨다. DOM 측정으로 안전영역·줄바꿈을 자동 검사할 수 있다는 게 결정적이었다.
- **타이포그래피로 브랜드 철학 표현**: 워드마크 Beau"T"는 "Beau"(부드러운 세리프=감성/F)와 "T"(인용부호로 강조된 딱딱한 산세리프=이성/T)의 대비로 "BEAUTY IS T, NOT F." 철학을 시각화한다.
- **7종 모듈 시스템**: 나열형 텍스트를 표·흐름도·벤다이어그램·시그널박스·콜아웃 등으로 구조화해, 목표 독자(중3 수준)에 맞춘 가독성을 확보했다.

## 🛠️ 적용법 가이드
1. 검증된 원천 콘텐츠(블로그·아티클 등)에서 속설 반박형 소재를 고른다 — 카드 1장=결론 1개로 쉽게 쪼개진다.
2. 참고 계정의 시각 문법(레이아웃·색·구조)을 분석하되, 정보 밀도는 자기 독자 수준에 맞게 낮춘다.
3. 캔버스 규격과 안전영역을 먼저 고정하고(1080×1350, 하단 260px), 이를 어기면 빌드 실패로 처리하는 자동 검증기를 만든다.
4. Figma MCP처럼 호출 제한이 있는 도구보다, DOM 기반으로 직접 측정 가능한 HTML→PNG 렌더링이 검수 자동화에 유리하다.
5. "특정 단어 금지"(예: PubMed) 같은 톤 규칙도 검증기에 포함시켜 사람이 매번 확인하지 않아도 되게 한다.

## 💼 활용 예시
- 이미 발행된 블로그/뉴스레터 아카이브를 보유한 크리에이터가 인스타그램으로 채널을 확장할 때
- 팩트체크형 콘텐츠 브랜드가 "근거 배지"(예: 참조 논문 N편) 같은 신뢰 신호를 카드뉴스에도 자동 반영하고 싶을 때
- Figma 플러그인 대신 코드 기반(HTML/CSS) 렌더링으로 카드뉴스 자동 검증 파이프라인을 구축하려는 경우

## ⚠️ 주의사항
- 인스타그램은 여러 장 업로드 시 기본적으로 1:1로 크롭한다. 4:5로 만든 카드를 그대로 올리면 위아래가 잘린다 — 실제로 2026-09-20 첫 업로드에서 발생한 실패 사례.
- 프로필 그리드는 4:5 게시물을 3:4로 좌우가 잘려 보여준다. 로고·텍스트·출처 표기는 이 안전영역 밖에 두면 안 된다.
- Unsplash 이미지 사용 시 `download_location` 엔드포인트 호출과 작가명 표기가 약관상 필요하다.
- Figma MCP는 연속 호출 제한이 있어 대량 카드 생성에는 부적합할 수 있다 — 검수까지 포함한 자동화라면 코드 기반 렌더링을 우선 검토할 것.
