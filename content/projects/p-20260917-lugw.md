## 🎯 핵심 요약

터미널이나 명령어 입력 없이, 전부 클릭과 붙여넣기만으로 Claude에 MCP(연동
프로그램/커넥터)를 붙여 노션·캔바·파일정리·영상편집·유튜브 분석 5가지를
자동화하는 완전 비개발자용 가이드다. 난이도 기준 추천 순서는 **유튜브 →
노션 → 캔바 → 파일정리 → 영상편집**이며, 하루에 5개를 전부 설치하지 말고
하나씩 늘려가라는 게 원문의 핵심 조언이다.

## 💡 핵심 인사이트

- **MCP는 Claude에게 손을 달아주는 부품**이다. Claude는 대화는 잘하지만 내
  컴퓨터나 계정을 직접 조작하지 못하는데, MCP(앱 안에서는 "커넥터"/"확장
  프로그램"으로 불림)를 연결하면 실제로 조작이 가능해진다 — 인스타그램에
  다른 앱 계정을 연결하는 것과 비슷한 개념.
- **플랫폼별 지원이 다르다**: 노션·캔바·유튜브는 웹/데스크톱/휴대폰 전부
  가능하지만, 파일정리·영상편집처럼 내 컴퓨터를 직접 만지는 기능은
  **데스크톱 앱 전용**이다.
- **무료 플랜은 커넥터 1개만 동시 연결 가능**하다는 안내가 있어, 여러 개를
  동시에 못 켜면 필요할 때마다 번갈아 켜야 한다.
- **난이도 순으로 시작하는 게 안전하다**: 유튜브(5번)는 설치 없이 5분,
  휴대폰으로도 가능한 가장 쉬운 항목 — 여기서 성공 경험을 만들고 나머지로
  넘어가는 걸 권장. 영상편집(4번)이 단계가 제일 많고 손이 많이 간다.
- **처음엔 접근 범위를 최소로**: 노션 연결 시 워크스페이스 전체가 아니라
  페이지 하나만 허용, 파일정리 연결 시 컴퓨터 전체가 아니라 다운로드
  폴더 하나만 허용 — 익숙해지면 그때 늘리라는 원칙이 반복해서 강조된다.

## 🛠️ 적용법 가이드

**1. 노션** (클릭 5번·5분·휴대폰 가능) — Claude 설정→커넥터→Notion 검색→
연결→로그인 후 페이지 선택(처음엔 1개만 허용)→새 대화에서 도구 아이콘으로
켜기. 주제만 던지면 새 페이지 생성+표 채우기, 기존 페이지 수정까지 가능.

**2. 캔바** (클릭 5번·5분·휴대폰 가능) — 같은 방식으로 Canva 커넥터 연결.
글 하나만 던지면 편집 가능한 캔바 캐러셀 파일이 계정에 생성된다(이미지 한
장이 아니라 편집 가능한 원본 파일이 나온다는 게 핵심).

**3. 파일정리** (데스크톱 앱 필요·10분) — 설정→확장 프로그램→Filesystem
설치→폴더 선택(다운로드 폴더 하나만). 옮기기 전 "무엇을 어디로 옮길지"
목록을 먼저 보여주고 승인 후에만 실행하는 안전장치가 있다.

**4. 영상편집** (데스크톱 앱 필요·30분, 5개 중 가장 손이 많이 감) — ①Node.js
설치(nodejs.org, LTS 버전) ②`claude_desktop_config.json` 설정파일을
메모장으로 열어 Claude가 알려주는 내용 붙여넣기(ffmpeg-mcp 저장소 기반)
③Claude 완전히 종료 후 재실행. 자르기·무음구간 삭제·영상 합치기가 가능하며
원본은 보존하고 사본만 생성.

**5. 유튜브** (설치 없음·5분·가장 쉬움) — 커스텀 커넥터 추가에 이름
`youtube-transcript`, 주소 `https://youtube-transcript.ai/mcp` 입력 후
저장·활성화. 링크 하나로 영상 전체 자막을 가져와 요약·번역·구간검색 가능.

## 💼 활용 예시

- **노션 자동화**: 회의록을 할 일 목록으로 변환, 콘텐츠 캘린더 자동 생성,
  흩어진 메모를 데이터베이스로 정리 — 회사 노션 운영 방식과 그대로 겹치는
  활용 영역
- **캔바 자동화**: 텍스트만 던지면 인스타 캐러셀 초안이 편집 가능한 캔바
  파일로 나와, 마케팅팀 콘텐츠 제작에서 디자이너 개입 전 단계까지 자동화
- **유튜브 분석**: 설치 없이 5분이면 되는 가장 낮은 진입장벽 — 경쟁사
  콘텐츠나 업계 세미나 영상을 빠르게 요약하는 용도로 팀 전체에 먼저
  전파하기 좋은 항목

## ⚠️ 주의사항

- 노션 연결 시 Claude가 "접근을 허용한 노션 내용 전체"에 동일하게
  접근하게 된다 — 회사 워크스페이스를 연결할 때는 페이지 단위로 최소
  권한만 허용할 것
- 영상편집(4번) 첫 명령에는 반드시 "원본 파일은 절대 덮어쓰지 마"라는
  문장을 넣을 것 — 원본 손실 사고가 여기서 가장 자주 발생한다고 원문이
  명시
- 유튜브 MCP는 외부 서버를 거치는 방식이므로 회사 내부 영상처럼 민감한
  콘텐츠는 넣지 말 것
- "설치했는데 Claude가 인식 못 함" 문제는 대부분 완전 종료(트레이 아이콘
  우클릭 종료, 창 닫기만으로는 안 됨) 누락이 원인
