## 📚 원본 링크
- https://lazyowen.com/guides/mcps (게으른 빌더 — 클로드 코드에 무조건 깔아야 하는 MCP 5개, 2026-08-06 갱신)

## 🎯 핵심 요약
클로드 코드는 기본 상태에서 인터넷 검색·브라우저 조작·이미지 생성이 전부 막혀 있어 학습 시점 이후 정보로 헛소리를 하기 쉽다. 이 가이드는 그 구멍을 메우는 MCP(Model Context Protocol) 서버 5종 — Perplexity(웹 검색), Playwright(브라우저 조작), Firecrawl(사이트 통째 수집), Glif(이미지 생성), Chrome DevTools(열린 탭 읽기) — 를 설치부터 연결 검증까지 순서대로 안내한다. 5개 중 키 없이 바로 되는 건 Playwright·Firecrawl·Chrome DevTools 3개이고, API 키가 필요한 건 Perplexity·Firecrawl(자체 실행 시)·Glif(로그인)이다.

## 💡 핵심 인사이트
- **하나만 깔아도 나머지 넷을 그대로 쓸 수 있다.** 5개가 서로 대체재가 아니라 각각 다른 구멍(웹검색/브라우징/문서수집/이미지생성/화면읽기)을 메우는 보완재이기 때문에 5개를 함께 쓰는 것이 전제다.
- **클로드는 도구를 명시적으로 지정하지 않아도 스스로 필요한 MCP를 골라 쓴다.** "Next.js 최신 버전 바뀐 점 3줄 정리해줘"라고만 말해도 자동으로 Perplexity를 호출하는 식.
- **설치 명령이 도구마다 다르다**: 키 불필요 3종은 `claude mcp add playwright -- npx @playwright/mcp@latest`, `claude mcp add chrome-devtools -- npx chrome-devtools-mcp@latest`, `claude mcp add --transport http glif "https://glif.app/api/mcp"`(Glif는 브라우저 로그인만 필요). 키 필요 2종은 `--env` 플래그로 API 키를 주입한다.
- **여러 도구를 한 문장으로 엮어 쓸 수 있다.** "최신 사용법 찾고, 공식 문서를 긁어서, 그대로 구성한 튜토리얼로 작성해줘" 한 문장에 Perplexity→Firecrawl→글쓰기까지 4개 도구가 순차 실행되는 예시가 소개됨.
- **CLI 버전과 MCP 버전은 별개 패키지다.** Playwright의 경우 테스트용 CLI와 MCP 서버가 다른 패키지라 설치 시 혼동하지 않아야 한다(별도로 팩트체크한 내용, 원문에는 없었으나 microsoft/playwright-mcp 공식 저장소 기준 확인).

## 🛠️ 적용법 가이드
1. 준비물 확인: `claude --version`, `node --version`으로 설치 여부 체크, `claude mcp list`로 이미 등록된 서버 확인(중복 등록 방지).
2. 키 없이 되는 3개부터 설치: Playwright, Chrome DevTools, Glif(로그인 필요) — 터미널에 명령 블록 통째로 붙여넣기.
3. 키 필요한 2개 설치: Perplexity·Firecrawl. 각각 API 키를 `--env`로 넘겨 등록.
4. `claude mcp list`로 각 서버가 Connected로 뜨는지 확인. Glif는 브라우저 로그인 전에는 "인증 대기" 상태가 정상.
5. 실제 사용: 도구를 지정하지 말고 자연어로 요청 — 클로드가 알아서 필요한 MCP를 호출.
6. 응용: 여러 MCP를 한 문장에 엮어 검색→수집→작성까지 한 번에 처리.

## 💼 활용 예시
- **웹 검색**: "Next.js 최신 버전에서 바뀐 점 3줄로 정리해줘" → Perplexity가 실시간 검색으로 답.
- **브라우저 테스트**: "TodoMVC 데모 열고 '장바구니 추가' 버튼 작동하는지 확인해줘" → Playwright가 직접 클릭·입력.
- **문서 수집**: "이 문서 사이트에서 핵심 기능 목록만 뽑아줘" → Firecrawl이 페이지 내용을 정리해 반환.
- **이미지 생성**: "게으른 로봇 이미지 만들어줘" → Glif가 완성된 이미지 URL을 반환.
- **화면 디버깅**: "지금 열려 있는 탭에 콘솔 에러 있는지 확인해줘" → Chrome DevTools MCP가 탭 목록·콘솔 메시지를 읽어옴.
- **복합 워크플로**: "최신 사용법 찾고, 공식 문서 긁어서, 튜토리얼로 정리해줘" → 4개 MCP가 한 번에 순차 실행.

## ⚠️ 주의사항
- API 키(Perplexity, Firecrawl)는 화면·로그에 노출되지 않도록 주의해야 하며, 이미 등록된 MCP 설정을 지우거나 덮어쓰지 않게 조심해야 한다(원문의 프롬프트 템플릿에 명시된 제약).
- Glif는 브라우저 로그인 세션에 의존하므로 로그인 세션이 끊기면 재인증이 필요할 수 있다.
- 원문은 이메일 등록 시 전체 8스텝(설치~실전 예시)이 열리는 그로스 콘텐츠 구조라, 공개된 Quick Start·역할 소개·키 없는 3개 설치까지만 무료로 확인 가능하고 STEP 4~8(키 필요 설치, 검증, 실전 조합)은 원문 상 잠금 상태였다 — 이 카드는 잠긴 구간 없이 페이지에 노출된 텍스트 기준으로 작성됨.
- 스타 수·저장소 경로는 이 카드 작성 시점(2026-09-29) GitHub API로 별도 재확인: microsoft/playwright-mcp(⭐36,900+), firecrawl/firecrawl-mcp-server(⭐7,500+), ChromeDevTools/chrome-devtools-mcp(⭐52,700+), perplexityai/modelcontextprotocol(⭐2,500+). Glif는 호스팅형 서비스로 별도 저장소 스타 지표가 의미 없음.
