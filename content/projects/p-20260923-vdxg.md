## 🎯 핵심 요약

혼자 하던 "조사→첫 문장→대본→디자인→발행→분석"을 Claude Code **서브에이전트 7개**(`.claude/agents/*.md` 파일 7개)로 나눠 맡기는 방법. 사람을 뽑는 게 아니라 지시문 파일을 만드는 방식이며, 설치에 약 **30분**. 핵심 원칙은 편집장(본인)이 사라지지 않는다는 것 — 승인 지점은 **딱 2곳**(아이디어 확정 시 / 발행 전)뿐이고 그 외엔 자동 진행.

## 💡 핵심 인사이트

- **직원 한 명 = 글 파일 하나**: Claude Code는 `.claude/agents/` 폴더의 `.md` 파일을 서브에이전트로 자동 인식 — 별도 등록 절차 없이 파일만 넣으면 끝
- **7개 역할의 실제 지시문까지 구체적**: 조사 담당은 "숫자·조회수를 지어내지 마라"는 원칙이 프롬프트에 명시돼 있고, 분석 담당도 "짐작하지 말고 준 숫자만 근거로" 규정 — 환각 방지 장치가 프롬프트 레벨에 내장됨
- **대본 규격이 숫자로 고정**: 대본 담당의 출력은 "40초(약 250자), 첫 줄→알맹이→솔직한 한계→CTA" — 감으로 쓰는 게 아니라 정량 규격
- **발행 담당에 "가자" 승인 게이트가 하드코딩**: "내가 「가자」라고 하기 전에는 절대 자동으로 올리지 마라"는 규칙이 지시문에 그대로 박혀있음 — 자동 발행 사고를 막는 명시적 안전장치
- **CLAUDE.md 회사 규칙 템플릿에 5개 공통 규칙**: ①내 말투로(뻔한 말투 금지) ②숫자·성과 지어내지 않기 ③경쟁자 구성만 참고, 내용 도용 금지 ④대본 전·발행 전 반드시 승인 ⑤분석은 실제 숫자만 사용

## 🛠️ 적용법 가이드

1. **0~5분**: Claude Code 설치, `content-team` 폴더에서 `claude` 실행, CLAUDE.md에 회사 규칙(분야·독자·말투·CTA) 작성
2. **5~15분**: `.claude/agents/` 폴더에 파일 7개 생성 — "이 안내문 보고 직원 일곱 명 파일 만들어 줘"라고 시키면 Claude가 뼈대를 잡아줌
3. **15~22분**: `brand/voice.md`에 예전에 잘된 캡션 3~5개 붙여넣기(말투를 가르치는 유일한 재료)
4. **22~30분**: "관리 담당, [주제]로 릴스 하나 만들어"로 테스트 — 승인 지점 2곳만 확인하면 끝까지 진행

이후 운영은 "관리 담당, 이번 주 릴스 3개 만들어" 한마디로 반복.

## 💼 활용 예시

- BeauT오빠 인스타 콘텐츠 자동화에 그대로 이식 가능한 구조 — 특히 "숫자 지어내지 마라"·"승인 게이트" 원칙은 현재 Insta-mag.auto 파이프라인에도 참고할 만함
- 서고 라이브러리 자체 운영(리서치→실행→발행 3단계)과 이 구조의 "조사→…→분석→다시 조사" 순환이 개념적으로 유사 — 서고에도 "분석 담당" 역할을 붙여 카드 조회수/반응을 추적하는 아이디어로 확장 가능
