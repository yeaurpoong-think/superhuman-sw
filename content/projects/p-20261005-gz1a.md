## 💬 사서 코멘트

> "와 이거 개쩐다. 400만 달러를 유치했다는 것도 임팩트가 있네."

## 🎯 핵심 요약

**MiroFish(미로피쉬)**는 상품·가격·광고 문구를 넣으면, 직업도 성격도 제각각인 **AI 페르소나 수천 명이 서로 토론**한 뒤 "이 사람들은 이래서 안 살 것 같다"를 보고서로 정리해 주는 **오픈소스 시장 반응 시뮬레이터**다. 한 줄로 말하면 **"내가 미처 생각 못 한 반대 의견을 출시 전에 미리 들어보는 도구"**다. 베이징의 20세 대학생이 AI를 활용해 약 10일 만에 만들었다고 알려졌다. 공개 직후 GitHub 트렌딩 1위에 올랐고 지금은 ⭐7.6만을 넘겼다. 중국 샨다(Shanda)그룹의 전략적 지원·인큐베이션을 받았고, 약 400만 달러(약 3천만 위안) 투자 유치로 화제가 됐다.

## 💡 핵심 인사이트

- **"연구소급 시스템을 대학생 한 명이 AI로 만들었다."** 원본 크리에이터가 이 도구를 소개한 진짜 이유다. "한번 써보세요"보다 AI 시대에 1인 개발자가 만들 수 있는 것의 스케일이 바뀌었다는 신호에 가깝다. 10일 개발 → 트렌딩 1위 → 대기업 인큐베이션·투자로 이어진 속도 자체가 뉴스다.
- **구조는 생각보다 단순한 4단계다.**
  1. 인물을 뽑는다
  2. 각자 성격·직업·소비 성향을 붙인다
  3. 몇 라운드 토론시킨다
  4. 보고서로 정리한다

  코드가 전부 공개돼 있어서, 같은 구조를 다른 도구(Claude 등)로 재현할 수 있다.
- **"찬성"보다 "반대 이유"가 가치다.** 내부 회의에서는 잘 안 나오는 "왜 안 사는가"를 다양한 페르소나 관점에서 미리 수집할 수 있다. 출시 전 리스크 점검용 섀도 소비자 패널에 가깝다.
- **한국에서도 파생이 나왔다.** 원본 릴스에 따르면 소셜 시뮬레이션으로 박사 학위를 받은 국내 연구자가 구조를 분석해 한국어판을 만들어 공개했다(원문 인용, 정확한 저장소는 특정하지 못함).
- **원본은 비용이 든다. 그래서 '경량판'이 의미 있다.** 원본을 그대로 돌리면 LLM API 호출이 많아 비용이 꽤 나간다(README에서도 "소모량이 크니 40라운드 미만으로 먼저 시도"를 권장). 원본 크리에이터는 같은 구조를 Claude에 붙여 넣기만 하면 되는 무료 프롬프트로 만들었다. 수천 명이 아니라 10명 남짓 규모지만, 놓친 반대 이유를 찾기엔 충분하다고 소개한다.

## 🛠️ 적용법 가이드

**A. 가볍게: Claude에서 '미니 MiroFish' 직접 돌려보기 (무료, 설치 없음)**

원본 크리에이터의 프롬프트는 댓글을 달아야 DM으로 받는 구조라 확보하지 못했다. 공개된 4단계 구조를 그대로 옮긴 예시는 다음과 같다.

```
당신은 소비자 반응 시뮬레이터입니다. 아래 순서로 진행하세요.

[입력] 상품: ○○ / 가격: ○○원 / 광고 문구: "○○"

1. 페르소나 생성: 이 상품의 잠재 고객 10명을 만드세요.
   각자 나이·직업·소득 수준·성격·소비 성향·평소 쓰는 대체재를 구체적으로 정하세요.
   (열성 구매자, 가격 민감형, 의심 많은 사람, 무관심층을 골고루 섞을 것)
2. 1라운드 — 각자 상품과 광고 문구를 보고 첫 반응(살지/안 살지 + 이유)을 말합니다.
3. 2~3라운드 — 서로의 의견에 반박하거나 설득당하며 토론합니다. 의견이 바뀐 사람은 이유를 밝힙니다.
4. 보고서 — 최종 구매 의향 비율, "안 사는 이유" TOP 5(언급 빈도순),
   가장 설득력 있던 반대 논리, 광고 문구·가격·상품을 어떻게 바꾸면 반대가 줄지 제안하세요.
```

**B. 제대로: 원본 MiroFish 설치 (개발 환경 필요)**
- 저장소: `github.com/666ghj/MiroFish` (AGPL-3.0)
- 준비물:
  - Node.js와 Python
  - OpenAI 형식 LLM API 키(README 권장은 알리바바 Qwen-plus)
  - Zep Cloud API 키(무료 월 할당량 있음)
- 실행:
  ```bash
  cp .env.example .env     # LLM_API_KEY, ZEP_API_KEY 등 입력
  npm run setup:all        # 전체 의존성 설치
  npm run dev              # 프런트+백엔드 실행
  ```
  또는 Docker로 띄울 수 있다: `docker compose up -d`
- 비용 주의: 라운드 수와 인원에 비례해 API 비용이 늘어난다. 처음엔 소규모·40라운드 미만으로 시작한다.

## 💼 활용 예시

- **신제품 가격 테스트:** 같은 제품을 2만9천 원과 3만9천 원 두 버전으로 넣고, 페르소나들이 무엇을 근거로 비싸다고 느끼는지 비교한다.
- **광고 카피 사전 검증:** 카피 A/B를 넣고 오해하거나 거부감을 느끼는 포인트를 집행 전에 수집한다. 실제 A/B 테스트 비용을 쓰기 전의 1차 필터로 쓴다.
- **해외 진출 시장 반응 가늠:** 국가·문화권별 페르소나를 설정해, 같은 상품이 시장마다 어떤 이유로 거절될 수 있는지 가설을 뽑는다(실제 시장 조사의 대체가 아니라 질문 리스트 생성용).

## ⚠️ 주의사항

- **시뮬레이션은 예측이 아니라 가설 생성이다.** AI 페르소나의 반응은 실제 소비자 데이터가 아니라 LLM의 추론이다. "놓친 반대 이유 찾기"에는 유용하지만, 수요 예측이나 의사결정의 근거 숫자로 쓰면 안 된다.
- **라이선스는 AGPL-3.0이다.** 원본 코드를 수정해 외부 서비스로 제공하면 소스 공개 의무가 생길 수 있다. 사내 실험용과 대외 서비스용을 구분할 것.
- **유사·사칭 사이트가 많다.** `mirofish.us`, `.ai`, `.work`, `.my` 등 이름을 딴 호스팅 사이트가 다수 검색되는데, 대부분 원 개발팀과 무관한 독립 운영 서비스다. 상품·가격 같은 내부 정보를 넣기 전에 운영 주체를 꼭 확인할 것.
- **원본 비용:** API 호출이 많아 그대로 돌리면 비용이 꽤 나간다.
