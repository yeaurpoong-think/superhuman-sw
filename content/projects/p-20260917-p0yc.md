## 🎯 핵심 요약

회사 공용 Hermes를 인사팀·재무팀 문의 봇, 팀 매니저 봇으로 도입하되 정보보안을 최우선으로 삼는다면, "폴더만 나누고 PC에 비밀번호를 거는" 방식으로는 부족하다. 같은 로그인 계정 안에서는 결국 누구나 그 폴더를 열 수 있기 때문이다. 핵심은 **① OS 로그인 계정 자체를 인사팀 전용으로 분리 → ② 그 계정 안에서 Hermes 프로필을 별도로 생성 → ③ 디스크 암호화로 물리적 탈취까지 막는** 3단계 구조다. 이 문서는 비개발자가 그대로 따라 할 수 있도록 실제 클릭 순서, 명령어, 확인 방법까지 전부 담았다.

## 💡 핵심 인사이트

- **"폴더 잠금"과 "계정 분리"는 보안 수준이 다르다.** 같은 Windows 계정으로 로그인한 사람은 관리자 권한이 있으면 언제든 다른 폴더를 열 수 있다. 진짜 경계는 OS가 계정 단위로 강제하는 파일 권한(ACL)이다.
- **Hermes는 "프로필"이라는 기능으로 완전히 독립된 에이전트를 여러 개 만들 수 있다.** 각 프로필은 메모리·대화기록·스킬·자격증명(API 키, 슬랙 봇 토큰)이 서로 완전히 분리된다. 한 프로필이 뚫려도 다른 프로필의 정보는 새지 않는다.
- **물리적 분실 대비는 계정 분리와 별개 문제다.** PC 자체를 도난당하면 로그인 계정이 나뉘어 있어도 디스크를 분리해서 파일을 빼갈 수 있다. 디스크 전체 암호화(BitLocker)가 이 마지막 구멍을 막는다.
- **슬랙 봇 토큰과 툴 권한도 계정 분리 원칙과 똑같이 적용해야 한다.** 계정은 나눠놨는데 봇이 워크스페이스 전체 채널을 다 읽을 수 있거나, 임의 명령 실행 도구(`terminal`)를 켜두면 분리 효과가 반으로 줄어든다.
- **가장 강력한 형태는 아예 별도 물리 기기다.** 예산이 허락하면 인사팀 전용 미니PC 한 대를 따로 두는 것이 "논리적 분리"보다 확실한 "물리적 분리"다. 계정 분리는 그 전 단계, 혹은 예산이 부담될 때의 현실적 대안이다.

## 🛠️ 적용법 가이드

### 0단계. 전체 그림 먼저 이해하기

```
[PC 한 대]
 ├─ 관리자 계정 (기존, 사장님/IT담당자용)
 │    └─ 여기서는 인사팀 폴더가 안 보이거나, 봐도 못 엶
 │
 └─ 인사팀 전용 계정 (새로 생성, 표준 사용자 권한만)
      └─ 이 계정으로 로그인해야만 인사 데이터 폴더가 열림
           └─ 이 계정 안에 Hermes 프로필 하나(예: hr-team)를 만들어서
              여기서만 인사 관련 봇을 돌림
```

디스크 암호화는 이 전체를 감싸는 마지막 껍질이라고 생각하면 된다. PC가 통째로 도난당해도 암호를 모르면 디스크 안 내용을 못 연다.

### 1단계. Windows에 인사팀 전용 계정 만들기 (관리자 권한 없이)

> Windows 11 기준. macOS를 쓴다면 아래 "macOS인 경우" 참고.

1. 기존 관리자 계정으로 로그인한 상태에서 **설정(⊞ Win + I)** 을 연다
2. **계정 → 가족 및 다른 사용자** 로 이동
3. **"다른 사용자 추가"** 클릭
4. "이 사람의 로그인 정보를 가지고 있지 않습니다" → "Microsoft 계정 없이 사용자 추가" 순서로 클릭 (회사 계정이 아니라 로컬 계정으로 만드는 것이 핵심 — 마이크로소프트 클라우드에 정보가 안 올라간다)
5. 사용자 이름을 정한다 (예: `hr-team`), 비밀번호를 설정한다 — **이 비밀번호는 인사팀 담당자만 알아야 한다**
6. 계정이 생성되면 목록에서 그 계정을 클릭 → **"계정 유형 변경"** → **"표준 사용자"** 로 반드시 지정한다 (관리자로 두면 안 됨 — 표준 사용자는 시스템 설정을 못 건드리고, 다른 계정 폴더에도 기본적으로 접근이 막힌다)

**확인 방법:** 로그아웃 후 `hr-team` 계정으로 로그인해서, 시작 메뉴에서 "제어판" 같은 관리 도구를 열어봤을 때 "관리자 권한이 필요합니다" 팝업이 뜨면 정상이다.

### 2단계. 인사 데이터 폴더를 그 계정 전용으로 격리하기

1. `hr-team` 계정으로 로그인한 상태에서, 이 계정의 사용자 폴더 안(예: `C:\Users\hr-team\`)에 데이터 폴더를 만든다 — 예: `C:\Users\hr-team\HR_Data\`
2. 이 폴더는 **다른 계정의 사용자 폴더 밖(`C:\Users\다른계정\`)에 두면 안 된다.** Windows는 기본적으로 각 계정의 `C:\Users\계정이름\` 폴더를 그 계정 소유로 설정해서, 다른 표준 사용자 계정은 못 들어오게 막아준다. 이 기본 규칙을 그대로 이용하는 것이 가장 실수가 적다.
3. 혹시 기존 관리자 계정에도 그 폴더가 보이는지 확인하려면: 관리자 계정으로 로그인 → `C:\Users\hr-team\HR_Data` 경로에 직접 접속 시도 → "액세스가 거부되었습니다" 메시지가 뜨면 정상 격리된 것이다 (관리자는 소유권을 강제로 가져올 수는 있지만, 최소한 우연히/무심코 여는 것은 막힌다)

**macOS인 경우:**
1. **시스템 설정 → 사용자 및 그룹 → 하단 자물쇠 클릭(관리자 비밀번호 입력) → "+" 버튼**
2. 새 사용자 유형은 **"표준"** 선택, 사용자 이름(예: `hr-team`)과 비밀번호 설정
3. 해당 계정으로 로그인 후 `/Users/hr-team/` 안에 데이터 폴더 생성 — macOS도 기본적으로 다른 표준 계정은 이 폴더에 못 들어온다

### 3단계. 그 계정 안에서 Hermes 프로필 만들기

`hr-team` 계정으로 로그인한 터미널(또는 Hermes CLI가 이미 설치돼 있다면 그 상태)에서:

```bash
# 인사팀 전용 프로필 생성 (기존 개인 설정과 완전히 분리된 새 프로필)
hermes profile create hr-team

# 대화형 설정 마법사로 슬랙 연동, 모델 선택 등 진행
hr-team setup
```

**여기서 중요한 것: `hermes profile create`로 만든 프로필은 메모리·세션 기록·스킬·API 키가 전부 별도 폴더에 저장된다.** 기존에 쓰던 개인용 Hermes와는 완전히 다른 "새로운 뇌"라고 생각하면 된다. 이 프로필이 인사 데이터와 슬랙 봇 토큰을 갖게 될 것이다.

### 4단계. 인사팀 전용 슬랙 봇 만들기 (기존 봇과 절대 같이 쓰지 않기)

1. [api.slack.com/apps](https://api.slack.com/apps) 에서 **"Create New App"** → 인사팀용 새 앱 생성 (예: 이름 "SR바이오텍 인사봇")
2. **OAuth & Permissions** 메뉴에서 아래 권한(Scope)만 추가한다 — 필요한 만큼만 준다는 원칙:
   - `app_mentions:read`
   - `channels:history`
   - `channels:read`
   - `chat:write`
   - `im:history`, `im:read`, `im:write`
3. **"Install to Workspace"** 클릭 → Bot User OAuth Token(`xoxb-...`로 시작) 복사
4. **Basic Information → App-Level Tokens** 에서 `connections:write` 스코프로 토큰 생성 (`xapp-...`)
5. 이 두 토큰을 `hr-team` 프로필의 설정에만 넣는다 (`hr-team setup` 진행 중 슬랙 단계에서 입력)
6. **이 봇은 인사팀 슬랙 채널에만 초대한다.** 회사 전체 채널이나 다른 부서 채널에는 절대 초대하지 않는다 — 초대하지 않으면 그 채널 내용을 원천적으로 볼 수 없다

### 5단계. 이 프로필에는 위험한 도구를 꺼둔다

`hermes tools` 명령으로 `hr-team` 프로필의 도구 목록을 확인하고, 아래처럼 정리한다:

- **꺼야 할 것**: `terminal`(임의 명령 실행), `code_execution`(코드 실행) — 이 봇이 서버 자체를 조작할 필요는 없다
- **켜둘 것**: `file`(인사 데이터 폴더 읽기용으로 필요하면), `memory`, `messaging`, 필요한 경우 `web`(공용 정보 검색용)

이렇게 하면 설령 봇이 오작동하거나 프롬프트 공격을 당해도, "인사 관련 대화만 가능하고 시스템을 건드릴 수는 없는" 상태가 유지된다.

### 6단계. 디스크 전체 암호화 (물리적 도난 대비)

**Windows (BitLocker):**
1. 설정 → 개인 정보 및 보안 → **장치 암호화** (또는 제어판 → BitLocker 드라이브 암호화)
2. C 드라이브에 대해 켜기 — 복구 키가 발급되면 **반드시 USB나 종이에 별도 보관** (마이크로소프트 계정에 자동 백업되는 옵션도 있으나, 완전히 로컬로 관리하고 싶다면 수동 백업 선택)
3. Windows Home 버전은 BitLocker 대신 **"장치 암호화"** 라는 이름으로 같은 기능이 제공된다(설정 → 개인 정보 및 보안 → 장치 암호화)

**macOS (FileVault):**
1. 시스템 설정 → 개인 정보 보호 및 보안 → **FileVault** → "켜기"
2. 복구 키를 애플 계정과 연결할지, 로컬로만 저장할지 선택 (로컬 보관 권장)

**확인 방법:** 재부팅 후 로그인 화면 전에 복구 키를 요구하는 화면이 나오지 않으면(정상적으로는 로그인 비밀번호만으로 풀림) 그냥 잘 설정된 것 — 복구 키는 "복구가 필요한 비상 상황"에만 쓰인다. 평소엔 로그인 비밀번호만 입력하면 된다.

## 💼 활용 예시

- **시나리오 1 — 인사팀 문의 봇**: `hr-team` 프로필 + 슬랙 봇을 인사팀 채널에 초대. 팀원이 "연차 며칠 남았어?", "출산휴가 규정이 뭐야?" 라고 멘션하면 답변. 급여·개인정보처럼 더 민감한 정보는 별도의 `exec`(경영진 전용) 프로필로 한 번 더 나눠서, 그 프로필에만 급여 데이터를 연결하고 경영진 채널에만 그 봇을 초대하는 식으로 이중 분리도 가능하다.
- **시나리오 2 — 팀 매니저 봇**: 같은 원칙으로 `team-manager` 프로필을 하나 더 만들어서 노션 팀 페이지를 읽고 마감일을 리마인드하게 할 수 있다. 이 봇은 인사 민감정보와 무관하니 `hr-team` 계정이 아니라 공용 업무 계정에 둬도 무방하다 — **민감도가 다른 봇은 계정 자체를 다르게 두는 것**이 이번 가이드의 핵심 원칙이다.
- **시나리오 3 — 예산이 생기면**: 지금은 계정 분리로 시작하고, 나중에 여유가 되면 인사팀 전용 미니PC(중고 NUC 등, 30~50만원대) 한 대를 따로 마련해 그 위에서 `hr-team` 프로필을 옮기면 물리적 분리까지 완성된다. 계정 분리 단계에서 만든 설정은 그대로 새 기기로 옮길 수 있다(`hermes profile export` → 새 기기에서 `hermes profile import`).

## ⚠️ 주의사항

- **표준 사용자로 지정하는 것을 빼먹지 말 것.** 관리자로 계정을 만들면 폴더 격리 효과가 사라진다. 계정 생성 직후 반드시 "계정 유형 변경 → 표준 사용자"를 확인한다.
- **슬랙 봇 토큰을 텍스트 파일이나 채팅으로 공유할 때 스크린샷으로 보내지 말 것.** 값이 잘 안 읽혀서 오히려 재입력을 반복하게 된다. 항상 복사-붙여넣기 텍스트로 전달한다.
- **복구 키(BitLocker/FileVault)를 잃어버리면 디스크 전체를 영영 열 수 없다.** 종이에 출력해서 회사 금고 등 물리적으로 안전한 곳에 보관하거나, 암호화된 별도 저장소에 백업해둘 것.
- **계정을 나눠도 백업 계획은 따로 필요하다.** 이 PC 한 대에만 인사 데이터가 있으면 고장·분실 시 데이터가 통째로 사라진다. 최소한 암호화된 외장 드라이브나 회사 NAS로 정기 백업을 걸어둘 것.
- **봇에게 필요 이상의 슬랙 스코프나 도구 권한을 주지 말 것.** "일단 다 켜두고 나중에 줄이자"는 접근은 보안 원칙과 반대 방향이다. 필요한 것만 켜고, 필요해지면 그때 추가한다.
